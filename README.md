# 品牌营销中枢：独立本地开发版

本目录是本次明确要求组装的可入仓独立本地开发项目，后续对此版本的维护入口在本目录。它与 runtime-baseline-20261023 的增量镜像快照不同：Dockerfile 使用公开基础镜像，构建不引用原服务器业务镜像、私密配置或本机绝对路径。源码来源记录见 provenance.json；该文件记录适配前的来源，不代表适配后文件哈希。

## 使用范围

- 素材中心：沿用现有 Vue 源码及真实上传、分类、收藏、原片／混剪素材库接口。
- 审核：沿用现有提审、审批／驳回、权限与投递门禁业务代码。
- 本地二创：增加持久化任务编排，FFmpeg 实际裁剪上传原片，成片写入混剪库。它是基础裁剪流程，不代表线上完整智能二创算法已移植。
- 外部投递：经过真实审核门禁，模拟平台成功、失败或超时，保存任务及回执；不调用真实平台。
- OA：本地虚构身份，真实业务权限判断仍由后端执行。
- SQLite 与本地 S3 协议适配器保存数据，使用独立 Docker 卷。

本初版没有接入完整的线上主中枢 React 界面、学习、直播、调度、经营看板、一创模型及完整智能二创服务。原素材中心页面仍包含一些线上功能入口，未配置其外部服务的功能不保证可用，不使用固定成功响应冒充真实接入。首批范围是素材 → 审核 → 基础视频任务 → 模拟投递。

## 在其他电脑启动

需要 Docker Engine 或 Docker Desktop，以及 Docker Compose v2。首次构建需要联网下载公开基础镜像、npm 和 Python 依赖，并安装 FFmpeg；无需安装宿主机 Node、Python 或数据库。请在有足够构建内存的电脑上执行；此项目没有在低内存环境完成测试。

```sh
git clone https://github.com/gsy-fddm/brand_market_center.git
cd brand_market_center
docker compose up --build -d
```

本目录内容应作为仓库根目录上传。无需连同父目录的 implementation、runtime-baseline 或历史代码一起上传。默认配置已写在 compose.yaml，.env.example 用于说明本地模式，不要求填写生产凭据。

访问 http://127.0.0.1:8095/，自动进入 `/local-dev/`。选择模拟身份，再进入素材与审核中心。若 8095 已被其他项目占用，请先在准备验收的电脑上协调该端口；本次没有停止或替换原有 8095 服务。

## 本地账号

| 角色 | 工号 | 用途 |
|---|---|---|
| admin | FD-990001 | 管理素材、配置及查看所有本地任务 |
| manager | FD-990002 | 审核主管 |
| member | FD-990003 | 上传及创建本地任务 |
| denied | FD-990004 | 检查拒绝访问流程 |

首页提供身份选择；素材中心若显示登录页，可使用对应工号与密码 `local-dev`。本地账号与口令均为公开的虚构测试值，不得部署到公网。端口默认仅绑定 127.0.0.1，业务服务位于内部网络。

## 建议验收链路（尚未执行）

1. 选择创作成员，进入素材中心的“视频素材”，上传一段 MP4，确认素材 ID。
2. 回首页输入原片 ID，创建基础二创任务；等待任务完成，记录混剪素材 ID。
3. 在素材中心选择混剪库并提审，切换审核主管进行审批；根据页面要求填写必要审核内容。
4. 在首页创建模拟投递，分别检查成功、失败和超时；未通过审核的素材应被拦截。
5. 切换未授权身份，确认业务访问被拒绝；普通成员只可查看自己的本地任务。
6. 重启 cloud 容器，确认素材、审核及任务记录仍存在，处理中任务可恢复。

## 启停与日志

```sh
docker compose logs -f cloud
docker compose ps
docker compose stop
docker compose start
docker compose down
```

`down` 默认保留数据卷；不要随意添加 `-v`，它会删除该项目的本地数据。任务工作目录在 cloud-data 卷的 `/data/jobs/`，本初版未提供自动清理策略。

## 开发与构建入口

- `backend/app/`：真实素材／审核业务代码，以及 local_database、local_identity、local_bootstrap、local_tasks、local_app 适配与本地编排。
- `frontend/src/`：当前素材中心维护源码；`package-lock.json` 固定 npm 依赖树。
- `adapters/object-store.mjs`：本地有限 S3 协议实现；不验证真实云存储签名，分片上限 32 MiB，合并文件上限 128 MiB。
- `gateway/`：本地入口与路由；统一公开端口 8095。
- `Dockerfile`：前端依赖安装、类型检查和打包，再构建 Python／FFmpeg 后端。
- `backend/requirements.txt`：Python 直接依赖版本声明；没有生成完整传递依赖锁文件。

SQLite 的首次建表与本地账号初始化位于 local_bootstrap.py；没有恢复线上数据库、组织花名册、上传素材、令牌或真实环境变量。数据库适配按本地模式显式选择，默认不会在缺少服务器密钥时自动回退。
