# v2.11.66 发布说明

发布日期：2026-09-01

## 一键做同款：来源输入与多任务并发

- 修复 URL、TaskID 被当前任务两秒轮询重复回填、用户输入看起来被锁定的问题。
- 点击任务中心“＋ 新建任务”后清空 URL、TaskID 和变更类型，自动聚焦 URL 输入框；打开历史任务时只回显该任务保存的来源。
- 当前任务处于拆解、生图或视频生成中时仍可继续新建；原任务不停止，新任务使用独立任务 ID 在后台并发处理。
- 新任务提交后立即刷新到左侧任务栏；来源、状态、画布、资产和结果均按任务 ID 隔离。
- 修复任务中心“＋ 新建任务”成功执行一次后没有恢复可点击的问题，支持连续创建多个任务。

## 发布门禁

- 一键做同款专项覆盖两个不同来源任务同时进入后台拆解、任务 ID 和来源数据隔离。
- 专项测试、完整串行测试、核心脚本语法检查及 `git diff --check` 必须通过。
- 生产流水线继续执行备份、候选镜像构建、服务器端测试、服务就绪和线上版本检查。
- 登录态线上验收只检查 v2.11.66、URL/TaskID 可编辑、新建任务清空输入和运行中任务不受影响；不提交新任务，不创建 LibTV 节点，不消耗图片或视频生成额度。
