# v2.10.2 发布说明

## 个人 FanDo 模型授权

- 飞书登录后可选择本人 FanDo `openclaw.json`，浏览器只提取 API Key，不上传完整配置文件。
- 文件路径会自动复制；首次选择后保存浏览器文件句柄，后续授权失效时可直接允许重新读取。
- API Key 按飞书用户隔离，使用 AES-256-GCM 加密保存，不再把服务器上的个人 FanDo 凭证共享给所有用户。

## 稳定性与可用性探针

- Qwen、生图和明星画面服务在每次请求时解析当前用户凭证，短期 `gen_token` 失效后自动重新换取。
- 导入时先换取临时 `gen_token`，再调用只读 `/v1/session` 最小探针；探针通过后才保存授权。
- 探针不触发生图或生视频，不消耗生成额度；401/403 会将当前用户授权标记为失效。

## 兼容性与安全

- 不涉及数据库迁移，原有任务、素材和 LibTV 个人绑定保持不变。
- 新增凭证文件属于运行时加密数据，不进入仓库、更新包或共享目录。
