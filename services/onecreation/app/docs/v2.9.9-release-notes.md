# v2.9.9 发布说明

## 一键换品原片首帧与播放稳定性

- 新首帧模块增加“原片”候选，可在确认“无字幕、首帧无需换产品”后直接沿用参考视频首帧。
- 原片首帧与平台新首帧、自定义上传统一使用同一套候选 Tab；可随时切换回“生成新首帧”。
- 沿用原片首帧时不调用 GPT Image 2 或 Seedream 5.0 Pro，视频换品仍继续使用已选产品参考图。
- 原片首帧标题与适用条件合并为同一行，两个操作按钮固定放在原片候选卡底部。
- 参考视频与首帧图片预览统一为 9:16 同高展示框。
- 任务轮询不再重复创建相同参考视频播放器，并阻止轮询请求重叠，保留播放位置和播放状态。

## 兼容性

- 既有任务没有首帧策略字段时继续默认生成新首帧。
- 下方 ShotPlan、视频模型设置、LibTV 任务、生成进度、成片预览和下载接口保持不变。
- 不涉及数据库或素材迁移。
