# v2.11.50 发布说明

## 一键做同款：历史案例治理

- “历史任务做同款”新增服务端实名管理员白名单，仅 `古广妹`、`舒豪`、`何雨庭` 可以跨账号查看案例、管理标签和删除案例。
- 普通用户继续只查看自己的历史案例；标签、删除和跨账号做同款均由后端执行权限校验，不能仅靠前端隐藏按钮绕过。
- 管理标签时重建案例 JSON 快照、刷新 OSS 对象和 MySQL 检索索引；新索引成功后清理旧快照。
- 删除案例时同步移除本机回退记录、数据库索引和 OSS 快照；OSS 清理异常会返回明确警告。

## 产品目录同步

- 凝颜产品从主站产品目录、OSS 产品资产聚合、一键做同款和人物工作台等所有产品选择入口统一隐藏。
- 内部产品资料与历史任务数据继续保留，避免旧任务恢复和兼容逻辑受影响。

## 失败原因与重新生成

- 失败记录包含具体环节、CLI/Qwen/下载日志原始原因、错误码、尝试次数和是否可重试，不再统一显示“生成失败”。
- 拆解、产品映射和资产准备失败可沿用原任务配置，从当前失败环节重新发起。
- 单个 SKU 视频失败可复用已经确认的资产与提示词单独重试，并创建新的目标画布，不重复生成已经成功的兄弟目标。

## 共享资产 OA 登录修复

- 修复中枢 OA 已登录、共享资产接口却再次要求飞书登录的认证链断层。
- 已通过中枢校验的请求向部门共享服务传递 OA 令牌；旧工作台票据继续兼容。
- 未经过外层中枢校验的 OA 请求不会被转发，避免绕过认证。
