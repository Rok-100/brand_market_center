# v2.11.55 发布说明

## 修复

- 修复飞书中枢共享资产 API 返回 2xx JSON、但因没有旧 OpenAPI 的 `ok: true` 包装而被误判为失败的问题。
- 中枢 OA 路径按 HTTP 2xx JSON 契约验收，并拒绝显式的 `ok: false`、`success: false` 或 `error` 响应。
- 旧工作台票据对应的 OpenAPI 继续严格要求 `ok: true`，不放宽旧接口契约。

## 验证

- 覆盖中枢未包装成功响应、中枢显式失败响应、旧 OpenAPI 缺少 `ok` 和旧 OpenAPI 正常响应。
- 发布后必须在飞书统一登录态确认资产库显示“资产目录已同步”，且没有共享目录降级警告。
