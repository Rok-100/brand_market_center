# v2.11.8 发布说明

## 修复内容

- 修复备用创意通道的 LibTV 视频节点已生成完成，但工作台仍停留在“等待生成进度 0%”且不回传的问题。
- 新增第三通道专属恢复接口：先只读查询原 `projectId + videoNodeName`，确认远端资源完成后再下载会员无水印原链。
- 恢复过程不会创建视频节点、不会再次运行生成命令，也不会重复消耗正式视频生成额度。
- 页面在轮询停滞、任务中断或服务升级重启后会自动检查原节点并恢复回传；资源仍在同步时继续退避等待。

## 任务关联与隔离

- 新建备用创意任务会持久化关联当前 AI 产品镜任务，刷新页面或切换任务后可从服务端恢复对应第三通道任务。
- 升级前已有且带任务中心 ID 的备用创意任务会在启动时自动补齐关联。
- 多视频任务逐节点恢复，完成后继续在第三通道输出框通过标签页展示。
- 三路制作和备用半自动通道未复用第三通道的可变状态、恢复集合或 API 命名空间。

## 验证与发布约束

- 覆盖可恢复条件、持久化中断恢复、任务中心关联、前端自动恢复和多结果回显测试。
- 发布验证不发起正式视频生成；线上恢复只下载已经生成的原节点结果。
