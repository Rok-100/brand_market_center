# v2.11.1 发布说明

## AI-KOC 原片结构拆解与新分镜编排

- 用户输入中的换行只作为排版，不再直接决定分镜；系统会忽略错误换行并保证新口播逐字、按原顺序完整落入新分镜。
- Qwen 3.7 深度分析同时输出原片逐镜结构和新口播分镜方案；新分镜记录对应的原片镜头、叙事功能、动作、转场和情绪依据。
- 新视频总时长按“原片时长 × 新口播有效字数 ÷ 旧口播有效字数”计算，再在 4–14 秒的单镜范围内完成分配；缺少可用旧口播时才使用语速估算兜底。
- 历史任务若缺少新版逐镜结构，在继续审核或生成前自动重新执行深度分析并升级分镜计划。

## 生成可靠性

- 生成前先解析最终资产引用，依次创建全部 LibTV 视频节点，并逐个回读节点提示词。
- 提示词仅统一 Windows/Unix 换行符后做严格全文比对，不忽略空格、标点或其他内容差异。
- 只有全部节点预检通过才同时启动生成；任一节点预检失败时整批停止，不会产生部分视频。
- 批次生成不自动重试，失败原因和并发批次清单写入任务输出，供人工复核后再决定是否重新提交。

## LibTV 画布

- 移除 AI-KOC 页面中的手动 LibTV 链接输入框。
- 复用工作台统一规则：按当前用户、LibTV 账号/团队、本机和 AI-KOC 模块复用项目，并为每个业务任务创建专属画布。
- 画布在任务首次提交生成时自动创建，任务页面展示画布入口。

## Skill 同步

- 仓库内置的 `koc-libtv-video-replication` Skill 已同步上述时长、原片逐镜、新口播重排、严格预检和并发启动规则。
- 平台内置的跨平台执行器与交互式 Skill 脚本遵守同一生成契约。

## 兼容性

- 不涉及数据库迁移，不删除既有任务、素材、成片或 LibTV 绑定。
- 旧任务按需升级分镜计划；已绑定的存量任务画布继续沿用。
