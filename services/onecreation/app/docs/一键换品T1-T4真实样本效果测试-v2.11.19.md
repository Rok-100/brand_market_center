# 一键换品 T1—T4 真实样本效果测试（v2.11.19）

测试日期：2026-08-21

测试环境：线上 `https://app.fandow.top/fd-026222/brand-marketing-workbench/`

测试范围：只验证 v2.11.19 的真实样本拆解、ShotPlan、关键帧、执行分类、视频生成提交与质检状态；本轮不修改代码、不重新发布。

## 1. 总结

四条许愿池真实视频均完成 Qwen 拆解、ShotPlan 和关键帧生成。T1 与预期 T4 样本生成了成片，但均进入人工复核；T2 在 LibTV 合规审核阶段失败；预期 T3 在生成前被规则引擎误判为 T4 并阻断。

因此，当前版本不能判定为“T1—T4 效果验收全部通过”。已确认两项需要进入下一开发阶段的规则/输入缺口：

1. 仅手部出镜、无人脸的产品操作镜头，会因“人物主要身份证据不足”被无条件升级为 T4，覆盖了本应优先处理的 T3 产品状态链。
2. 许愿池中的目标动作要求没有输入一键换品引擎。若复杂性只存在于需求文本、而不在参考视频画面中，规则引擎无法识别并提前阻断 T4。

同时确认：多人物硬切样本能按五官、服装、发型和镜头事实保留不同人物身份，没有因“都是女性/男性”被合并为同一人物或判定无用。

## 4. 验收边界

- 本轮完成的是线上流程与规则效果测试，不是四条成片的最终视觉验收。
- 浏览器下载链路受登录态保护，本轮未成功将两条成片下载到本地，因此不能声称产品外观、动作一致性和画面质量已经人工观看通过。
- 两条“等待人工复核”不能计为自动质检通过。
- 测试没有修改生产数据结构、数据库、对象存储或策略管理台，也没有重新部署。

下一阶段应只修复“T3/T4 分类与需求输入”：对无人脸、仅手部的产品镜头取消人物身份证据型 T4 误判，同时把可选的目标动作/换品要求纳入分析与确定性分类；并增加上述两条真实样本回归测试。完成后再复跑四条效果测试。
