# v2.11.14 发布说明

## AI 产品镜 LibTV 项目归并

- 三路制作、备用半自动通道和备用创意通道的新任务统一使用 `AI产品镜工作台-电脑-设备后8位` 作为 LibTV 项目。
- 每个任务仍按任务中心的独立任务 ID 创建一张画布，画布名称继续使用 `YYYY-MM-DD-MMDD 通道任务NN`，不会把不同通道的视频节点放进同一张画布。
- 备用创意通道只调整 LibTV 项目路由；其 `creative_instruction_showcase` 工作流、API、提示词模板、素材、轮询、结果映射和多视频节点逻辑均保持独立。
- 已绑定旧版“备用创意通道工作台”项目的历史任务继续复用原画布，保证已有链接和生成结果可恢复；不执行自动迁移。

## 验证

- 新增三个通道共用项目、按任务分开画布的回归断言。
- 验证备用创意接口仍使用独立命名空间，但新任务明确路由到 AI 产品镜项目。
- 自动化验证不创建真实 LibTV 项目、画布或视频节点，不消耗生成额度。
