# v2.11.16 发布说明

## AI-KOC 生图自动降级

- 人物场景候选图首选 `GPT Image 2`（`openai/gpt-image-2`）。
- GPT Image 2 生图请求返回 HTTP 401 时，自动切换为 `Seedream 5.0 Pro`（`doubao-seedream-5-0-pro-260628`）。
- 首次降级后为当前任务启用熔断状态，剩余候选图直接走 Seedream，避免重复请求故障模型。
- 仅 HTTP 401 触发自动降级；403、超时、配额、合规和 5xx 错误继续保留原始失败信息。
- 任务记录、检查点、候选图和资产审核文件保存实际模型与降级原因，前端候选区同步展示。

## 验证

- 新增真实 HTTP 客户端 401 → Seedream 降级测试，以及非 401 不误切、任务级熔断与审计留痕测试。
- 全量 126 个自动测试文件通过。
- 发布过程不创建 LibTV 视频节点，不消耗视频生成额度。
