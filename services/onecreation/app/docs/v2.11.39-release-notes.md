# v2.11.39 发布说明

发布日期：2026-08-25

## 一键换品首帧、ShotPlan 与执行规则体验优化

- 用户点击“分析参考视频并生成新首帧”后，系统继续沿用服务端既有的分析与首轮生图流程，自动生成 V1、V2；首轮两个候选全部结束前，页面不再提前显示“+ 生成2张新首帧”，避免误触产生 V3、V4。
- 首轮 V1、V2 成功、失败或失效后，原按钮才切换为“+ 生成2张新首帧”。后续批次仍按 V3/V4、V5/V6 递增，不覆盖已有候选。
- 视频提交门禁改为依据真实上游状态派生：新首帧、口播、已确认 ShotPlan、必需关键帧和模型兼容性全部就绪，且没有首帧或关键帧正在生成时，自动开放“确认ShotPlan并生成”。服务端原有提交前置校验保持不变。
- 原关键帧与新关键帧统一使用同宽预览；生成结果区移除重复嵌套边框和重复“已选用”页签文字，保留重新生成、候选切换、选用和删除全部功能。
- 新增可隐藏的“当前执行规则”面板，使用 8 条说明解释替换模式、首帧、Qwen 分析、XingChenASR 转写、新口播确认、ShotPlan、关键帧、视频提交、自动验收和后台任务恢复。隐藏状态只保存在当前浏览器，不影响任务数据。

## 兼容与安全边界

- 没有修改 `XingChenAGI/XingChenASR-Diarize-V3.0` 的服务端共享密钥读取方式、ASR 接口契约或账号数据隔离规则。
- 没有修改产品契约来源，仍以 `app/assets/product-workflows-runtime/product-profiles.json` 为当前权威资料。
- 没有删除页面按钮或关键帧操作能力，也没有放宽运行中图片任务对视频提交的阻断。
