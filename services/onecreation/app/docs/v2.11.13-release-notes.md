# v2.11.13 发布说明

## AI-KOC 中间主体页面

- 左侧任务中心、顶部导航和五步流程保持现有结构与功能不变。
- 中间主体仅直接展示产品 SKU、原片参考视频、产品资产图、新旧口播文案、默认沿用原片口音和可选人物场景图。
- 拍摄方式、拆解方式、产品露出、互动和其他校正项统一收纳到高级补充项，默认由原片深度拆解决定。
- 自动处理进度按原片深拆、人物候选、口播与分镜重排、生成回传四阶段展示。
- 三张人物候选图按 9:16 单列展示；只有进入人工选择或人工复核状态时，才显示对应操作区。
- Qwen 原片深拆、详细分镜与提示词可按需查看，分镜可修改并保存，确认后才提交生成。

## 生成结果与规则

- 视频生成参数、LibTV 画布、单个分镜状态和成片播放统一回传到生成结果区域。
- 视频模型固定为 `Seedance 2.0 VIP`，模式固定为“全能参考”，比例固定为 `9:16`；清晰度支持 `720P` 与 `1080P`，默认 `720P`。
- 右侧当前执行规则保留全部内容，并支持收起和展开。
- 新任务拍摄方式默认逐镜继承 Qwen 原片深拆中的机位、视角、景别、构图和运动关系；只有人工选择固定或手持模式时才覆盖。

## 验证

- 新增主体页面结构、人工审核门槛、9:16 人物候选、自动进度、规则收起和自动拍摄逻辑测试。
- 全量自动化测试通过；测试和发布检查不创建正式 LibTV 视频任务。
