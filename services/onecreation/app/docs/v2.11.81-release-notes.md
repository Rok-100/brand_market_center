# v2.11.81 发布说明

发布日期：2026-09-04

## 一键做同款：上游图片逐图独立审计

- 源画布拆解由“多张图片一次提交”改为“每张上游图片单独提交一次”，避免相似人物关键帧之间发生视觉串扰。
- 每次主审请求仅携带当前图片，并按该图片的 `nodeKey` 保存结果；不再要求模型生成跨资产的 `videoType` 或 `summary` 汇总结论。
- 单张图片审计失败或未返回有效资产判断时，仅该图片采用保守处理，其他图片继续使用各自独立结果。
- 保留 v2.11.80 的疑似漏检单图高清二审、源 SKU 图片身份比对和人工“需要换品 / 直接复用”覆盖能力。
- 更新一键做同款静态资源缓存版本为 v2.11.81。

## 发布门禁

- 回归测试验证三张上游图片产生三次独立审计请求，且每次请求只包含一张图片。
- 一键做同款专项测试、核心 JavaScript 语法、差异格式检查和完整串行回归必须通过。
- 发布后只执行版本、服务健康、页面静态资源及只读接口检查，不触发图片或视频生成。
