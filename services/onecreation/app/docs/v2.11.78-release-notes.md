## 一键做同款：源画布资产可视化

- 阶段 02“源画布拆解”将原“类型 / 角色”文字列改为“源资产预览”。
- 图片资产显示真实缩略图并支持点击放大查看原图。
- 视频资产显示视频预览卡并支持弹窗播放、进度控制和全屏查看。

- 弹窗关闭后停止并清理媒体，避免音频或视频在后台继续播放。
- 后端 `mediaType`、`role`、节点映射、上传和归档契约保持不变。
- 更新一键做同款静态资源缓存版本，确保发布后加载 v2.11.78 前端资源。
