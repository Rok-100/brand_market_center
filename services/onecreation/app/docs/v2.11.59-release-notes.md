# v2.11.59 发布说明

## 功能内容

- 一键做同款接入统一任务中心，新任务按日期与当日序号命名；一个业务任务对应一个 LibTV 画布。
- 创建任务时智能识别并剔除原片产品，只向用户展示其余可换 SKU；识别置信度不足时保留人工核对入口。
- 保留只读、可复制的源视频原始提示词；为每个目标 SKU 生成独立、完整、可编辑的 `variant_prompt`。
- 用户确认后的 `variant_prompt` 直接作为对应 LibTV 视频节点的最终业务提示词，仅在提交前确定性映射真实 `nodeKey`，不做隐藏二次改写。
- 多个 SKU 在同一画布内使用不同上游节点和视频节点并发生成；页面回传共享画布地址与每个 SKU 的成片。
- 视频节点名与下载文件名包含 SKU 产品名称，失败重试继续复用原任务画布。

## 验证口径

- 双 SKU 生成只调用一次 `project create`，并在同一 `projectId` 下并发执行两个独立 `node create --run`。
- 两个视频节点分别使用各自确认后的最终提示词，不残留原片 SKU 产品事实，节点名和成片名均包含目标 SKU 名称。
- 专项测试 18/18、完整回归 682/682 通过；发布验收不创建真实 LibTV 生成任务，不消耗生成额度。
