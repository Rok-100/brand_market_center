# v2.11.101 发布说明

## 发布内容

- 提示词库新增正式案例治理入口：案例归属人可新增、删除自己的合格成片案例，实名管理员可跨归属操作，其他用户保持只读。

- 同一 SKU 下按节点重复展示的产品身份图入口合并为一个统一修正窗口；用户先选择要调整的节点，场景节点继续清理 OpenCV 参考并生成下一轮，独立产品节点继续直接使用 OSS 原图。
