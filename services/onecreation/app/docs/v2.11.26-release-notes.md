# v2.11.26 发布说明

## 新首帧即时反馈

- 用户点击“+ 新首帧”后，页面立即创建并激活新的候选版本页签，显示准备输入和生成阶段，无需等待图片模型完成才看到反馈。
- 后端先持久化正式 `generating` 候选，再以 HTTP 202 返回并继续异步生图；同一任务已有生成中候选时禁止重复追加。
- 成功、失败和超时继续回填同一候选；最新成功候选仍自动选用，既有首帧依赖和 ShotPlan 重构规则不变。

## 口播决策边界

- “只换口播”和“产品+口播”任务在视频制作正式提交前，仍可切换沿用旧口播或使用新口播，并修改新口播逐字文案。
- 口播选择、版本号和 SHA-256 持久化保存；点击“确认ShotPlan并生成”时先保存最终选择，再以同一快照编译音频、提示词和 LibTV 节点。
- 制作提交后前后端同时锁定决策；生成失败或中断后的合法重试可创建下一决策版本，历史生成记录不被改写。

## 暂时隐藏未开放入口

- 首页和一创制作页暂时隐藏“AI明星画面生成”，但保留 `/person-studio/` 路由、独立服务和后续开发能力。
- AI产品镜的三条制作通道暂时隐藏 Seedance 2.5 与 Kling O3，只向用户展示当前开放的 Seedance 2.0 VIP。
- Seedance 2.5、Kling O3 的模型定义、模式配置和后端实现全部保留，后续开放时无需重建接口。

## 发布工作流可识别名称

- 发布工作流新增必填内容摘要，流水线名称统一显示为“发布 v版本号：内容摘要”。
- PowerShell 发布入口支持从 UTF-8 文件读取摘要并执行中文可读性校验，避免版本列表只有版本号或出现乱码。
- 历史工作流名称不改写；新格式从 v2.11.26 发布开始生效。

## 验证与发布边界

- 三项功能在独立分支完成专项与完整回归后合入同一发布分支，统一升级一次版本并执行最终完整回归。
- 自动发布执行测试、备份、服务切换、健康检查和版本回读，不创建正式 LibTV 视频生成任务，不消耗视频生成额度。
