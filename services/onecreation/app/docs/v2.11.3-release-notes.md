# v2.11.3 发布说明

## AI-KOC 分镜编排

- 新片总时长继续严格按“原片时长 × 新口播有效字数 ÷ 旧口播有效字数”计算。
- 最终分镜数量改为以 13 秒为中心、优先落在 12–14 秒；Qwen 返回的过短语义段会按新口播语义边界重新归并，输入换行仍不参与分镜判断。
- 新增 60 秒、7 个语义段重排为 5 个正常 KOC 分镜的回归测试，逐字、逐标点和总时长均保持一致。

## 产品露出映射

- Qwen 深拆 JSON 升级为 `koc-source-structure-v2`，每个原片镜头必须输出 `productVisible` 和 `productEvidence`。
- 新分镜映射到产品可见的原片镜头时自动标记为产品露出，并要求连接用户上传的目标产品素材；用户手填的新视频露出分镜仅作为额外补充。
- 资产审计、提示词包和任务卡片统一显示自动映射后的真实露出分镜；检测到露出但缺少产品图时阻止继续。

## LibTV 参考音频

- AI-KOC 从本地原片视频音轨直接提取逐分镜参考音频，不调用 LibTV 画布的“音频分离”。
- 输出统一为 `.mp3`、MP3 编码（`libmp3lame`）、192 kbps、44.1 kHz、双声道。
- 每段音频不超过对应视频分镜时长且不超过 14.8 秒；提取完成后和上传 LibTV 前均使用 ffprobe 强校验，并复核文件哈希。

## 验证

- 覆盖新旧口播比例总时长、错误换行不影响分镜、Qwen 语义段重排、原片产品露出自动继承、MP3 编码与上传前校验。
- 完整自动化回归通过后发布，不在发布流程中发起正式视频生成或消耗 LibTV 额度。
