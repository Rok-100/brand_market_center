# v2.11.27 发布说明

## 首帧与关键帧产品连续性

- 用户选定的新首帧成为最终视频 0 秒产品状态最高真值，固定产品数量或量感、尺寸模板、方向、堆叠布局、人物接触和遮挡。
- 后续新关键帧只负责对应时间戳的状态，并必须继承首帧及前序动作结果；未来关键帧不得提前覆盖 0 秒首帧。
- 从堆叠中拿起单件产品时只移动该件，其余产品只允许最小重力沉降，禁止整体漂移、重排、复制或消失。

## 证据驱动的产品身份编译

- 目标产品图是产品身份、包装结构、颜色、比例、Logo、标签、材质和内容物的最高真值。
- 旧产品盒、瓶、罐、袋、片类型只能定位需要删除的对象，不能决定目标产品包装层级。
- SKU 文字元数据仅辅助识别，不能压过用户实际选中的图片；没有可靠图片证据时统一称为“目标产品”。
- 提交前阻断“外盒对外盒”等无证据层级硬指令，以及只供程序执行的编译和 QA 字段泄漏。

## 可审查的视频提示词

- 内部 Generation Planning 编译器继续负责首帧依赖、关键帧时间轴、人物连续性、产品状态链和数量连续性。
- 最终交给视频模型的提示词只包含编译结果和必要约束，不包含 schema、QA 检查码或重复任务契约。
- 不设置固定字符数上限；通过核心章节唯一性和内部字段隔离保证提示词去重且可审查。

## 新口播逐字验收

- 从生成 MP4 提取独立单声道 16kHz MP3，并上传为真实 LibTV 音频节点后执行逐字转写。
- 新口播全文只出现一次并具有音轨最高优先级；时长不足只能加快语速或缩短停顿，不能删字、换词、调序或提前截断。
- 转写不可用或与锁定文案不一致时，成片只标记为可预览，不计入合格成片，并保留一次定向重试。

## 验证与发布边界

- 功能分支全量 582 项测试通过；发布批次将再次执行完整自动测试、备份、容器健康检查和版本回读。
- 发布后使用 `0822测试01` 原素材重新生成，人工验收首帧产品形态、关键帧时序、堆叠库存连续性和完整新口播。
- 本版本不涉及数据库、配置或素材迁移。
