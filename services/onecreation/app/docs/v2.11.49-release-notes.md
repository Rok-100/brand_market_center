# v2.11.49 发布说明

## 一键做同款：产品形态映射

- SKU 与展示形态拆分管理，七款产品资料适配零售外盒、主容器、单片/单支、内容物、开启、使用和组合状态。
- 蛋白喷雾当前默认使用瓶体 `primary_container`，尺寸比例固定为 `53∶53∶180`；未登记尺寸的外盒保持不可选，不由模型补造。
- Qwen 拆解逐 nodeKey 输出产品层级、形态、视角、状态、动作、场景/人物/手部接触、置信度和证据。
- 每个产品承载节点分别匹配目标 SKU 的 OSS 资产；独立产品资料图直接使用 OSS 原图，不调用生图模型。
- 不同形态、视角或状态的独立资料节点禁止默认复用同一张目标资产。

## 生成前确认与风险控制

- 新增“产品形态与节点映射”确认页，确认前不会调用 Qwen 生图编译、GPT Image 2 或 Seedream。
- 尺寸比例差不超过约 15% 为低风险、15%–40% 为中风险，超过 40% 或方向/产品层级变化为高风险。
- 高风险需要用户明确确认；动作冲突必须填写目标产品合法动作改写方案。
- 缺目标尺寸或缺对应 OSS 资产时阻止继续，并展示资料缺口报告。
- 映射、置信度、风险、资料缺口和用户确认结果写入任务记录与成功案例快照。
- 完全新建和历史任务做同款均使用同一映射闸门。

## 验证与发布

- 燕窝罐换次抛外盒、蛋白喷雾瓶体、正背面 OSS 分别映射、跨视角禁止复用、动作冲突及资料缺口均有自动化覆盖。
- 发布前完整 `app/tests/*.test.js` 回归必须全部通过。
- 生产流水线继续执行备份、完整测试、候选镜像校验、服务就绪与线上路由检查。
- 线上核验不创建正式 LibTV 生图或视频任务，不消耗生成额度。
