# v2.11.46 发布说明

## 单视频裂变 LibTV 画布

- 移除高级设置中容易造成误解的手动 `LibTV链接` 输入框，改为“LibTV画布自动管理”只读说明。
- 新任务不再接收或提交固定的 `libtvUrl` 默认地址；系统继续根据当前 LibTV 活跃账号和业务任务ID自动创建独立画布。
- 同一任务的再次生成、修改后生成及重试继续复用原画布，画布创建成功后仍在任务状态区回传真实可点击地址。
- 历史非统一画布任务继续兼容已保存的 `libtvUrl`，本版本不改变个人账号与团队账号的选择规则。

## 验证与发布

- 发布前运行单视频裂变与统一画布专项、完整自动化回归、前后端脚本语法检查和 `git diff --check`。
- 浏览器核验高级设置说明块正常显示、旧链接输入框已移除且页面没有横向溢出。
- 发布流水线继续执行生产备份、完整测试、部署、服务就绪和线上路由检查；不会创建正式 LibTV 视频生成任务或消耗视频额度。
