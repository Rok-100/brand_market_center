# v2.11.72 发布说明

## 一键做同款：精简全局任务状态

- 移除各步骤右侧内容区顶部重复出现的大尺寸任务状态卡。

- 更新静态资源缓存版本，避免发布后继续加载 v2.11.71 页面资源。
