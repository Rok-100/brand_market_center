# v2.11.64 发布说明

## 功能内容

- 待配置任务重新打开或轮询刷新时，页面自动保留任务的 LibTV 画布 URL、成功视频 TaskID 和“本次只允许改变”选项，便于用户核对后继续配置。
- LibTV 画布输入框明确展示标准格式 `https://www.liblib.tv/canvas?spaceId=5429958&projectId=原来的projectId`，并拒绝 `/canvas/share` 分享地址。
- “查看源视频原始提示词”的展开状态按任务持久保存；除非用户主动隐藏，后台轮询与任务重绘不会将其收起。
- 新增可回退的“替换数量控制模板”：根据产品尺寸、包装形态、摆放方向与镜头角度计算智能建议数量，同时支持保持原数量、自定义数量、数量加减和排列方式选择。
- 包装层级变化或数量差异达到两倍时要求高风险确认；严格数量默认开启，8 个及以上目标先确认静态关键帧。缺少尺寸、包装层级或 OSS 白底资产时明确阻断智能换算，不伪造结果。
- 用户确认后的目标数量、真实尺寸、排列方式和清除旧产品要求作为硬约束进入首轮/第二轮生图、视频提示词及视频质量校验；服务端和单目标均可关闭模板并回退旧流程。

## 验证口径

- 水润面膜外盒在 45° 镜头下替换为燕窝面膜罐的校准样例为 3 盒建议 16 罐、合理范围 12–16 罐。
- 页面已核对 URL/TaskID 保留、源提示词展开持久化、数量加减转自定义模式、严格数量、高风险确认、关键帧提示和回退开关。
- 一键做同款数量与轮次专项 11/11、完整串行回归 696/696 通过；核心脚本语法检查与 `git diff --check` 通过。
