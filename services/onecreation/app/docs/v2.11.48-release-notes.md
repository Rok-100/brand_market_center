# v2.11.48 发布说明

## 一键做同款：画布访问校验

- 创建任务后先使用当前 LibTV 账号检查源画布是否可访问。
- 无法访问时返回明确提示并终止后续拆解和生成，不自动切换账号。
- 页面单独展示画布访问异常，避免用户把权限问题误判为提示词或模型失败。

## 成功拆解即归档

- 成功拆解源视频节点后立即生成 `source_ready` 模板，不再等待生图或生视频完成。
- 快照完整保存源提示词、视频生成参数、全部上游资产、nodeKey 输入顺序及提示词中的 nodeKey 引用。
- 模板 JSON 写入平台 OSS，结构化索引写入素材中心 MySQL，并立即出现在“历史任务做同款”。
- OSS 或数据库暂时不可用时保留本地记录并进入自动重试队列。
- 正式提示词库仍只展示已经生成成片的 `completed` 案例。

## 验证与发布

- 一键做同款专项、完整自动化回归、核心脚本语法与差异格式检查必须全部通过后才允许合并。
- Qwen 返回中文“登录凭证已过期”时，运行时会继续验证同一平台的下一份共享凭证，不会在首个过期凭证处提前终止。
- 平台持久化 Qwen 凭证仍保持最高优先级；仅当全部持久化凭证过期时，才使用发布流水线配置的 Qwen Secret 作为最后一级回退。
- 实际业务请求使用当前登录用户导入的个人 Qwen 授权；服务器共享授权过期只产生发布告警，不再误阻断与共享凭证无关的版本发布，未知错误仍会回滚。
- 生产流水线继续执行备份、完整测试、部署、服务就绪和线上路由检查。
- 发布核验不创建正式 LibTV 视频生成任务，不消耗视频额度。
