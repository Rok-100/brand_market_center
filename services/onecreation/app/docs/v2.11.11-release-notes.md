# v2.11.11 发布说明

## AI-KOC 视频生成参数

- 前端新增折叠式视频生成参数区域：模型固定为 `Seedance 2.0 VIP`，模式固定为“全能参考”，比例固定为 `9:16`。
- 清晰度支持 `720P` 与 `1080P`，默认使用 `720P`；选择结果随草稿与任务持续保存。
- 后端只接受上述两档清晰度，并把同一参数写入分镜计划与 LibTV 视频节点；任务配置和节点设置不一致时阻止生成。
- 自动合规审核新增“视频生成参数”检查项，展示最终模型、模式、清晰度与比例。

## 人工审核与页面交互

- 等待人工审核时，可展开查看 Qwen 原片深度拆解与按新产品生成的详细分镜。
- 支持修改分镜功能、产品露出和最终 LibTV 提示词；锁定口播、分段时长和总时长不可在审核阶段修改。
- 保存分镜后重新生成提示词与资产审核文件，并再次执行本地合规检查；确认生成时校验最新审核版本，避免提交旧内容。
- “沿用原视频口音、语气与节奏”改为默认开启的正向选项；右侧当前执行规则增加隐藏/展开按钮。
- 左侧任务中心、顶部导航、任务操作按钮和五步流程保持原有结构与功能。

## 验证约束

- 新增 720P/1080P 参数贯通、LibTV 节点参数一致性、参数错配阻断、人工分镜修改和锁定口播保护测试。
- 全量自动化回归通过后发布；验证过程不创建 LibTV 正式视频生成任务，不消耗视频额度。
