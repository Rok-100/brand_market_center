# v2.11.69 发布说明

发布日期：2026-09-02

## 一键做同款：稳定播放与上游资产重构全局化

- 结果区轮询收到相同数据时复用现有视频播放器，不再重复销毁与重建 DOM，保留播放进度、缓冲和全屏状态，解决视频回传后的频繁闪屏。
- 产品审计文字确认存在旧产品像素时，不再被矛盾的布尔字段降级为源图复用；含旧产品的源图必须进入重构链路。
- 下线投影面积、固定数量和跨图数量换算，改为按每张源图检测到的实例逐槽位一对一替换，不写死 SKU、数量或坐标。
- OpenCV 几何服务按运行时源实例和目标比例生成布局、编辑遮罩、产品保护层、融合环和阴影提示；内网产物先转存到图片模型可访问的地址，预览图不作为模型输入。
- 阶段 03 展示并保存完整 nodeKey 上游资产路由清单；提交视频前校验每个节点均明确路由为源图复用、OSS 直连或候选生图。
- 几何、形态映射、OSS ID 和数量模板只服务于上游资产重构，不再流入最终视频提示词。
- 每个重构节点首轮固定生成 2 张图，用户可查看实际生图提示词，并通过“+ 重新生成”以选填纠偏发起第二轮 2 张；首轮结果保留，第三轮被阻断。
