# v2.11.56 发布说明

## 修复

- 飞书中枢共享资产路径以“HTTP 2xx 且正文成功解析为 JSON”为成功基础，不再要求响应头必须声明 `application/json`。
- 3xx 重定向不再误入成功分支；显式的 `ok: false`、`success: false` 或 `error` 仍会被拒绝。
- 无效响应会显示 HTTP 状态、Content-Type 和顶层字段名，便于继续定位且不暴露字段值或凭证。
- 旧工作台票据对应的 OpenAPI 继续同时要求 JSON Content-Type 与 `ok: true`。

## 验证

- 覆盖非标准 Content-Type 的中枢 JSON、解析失败、显式失败、旧 OpenAPI 严格契约和安全诊断信息。
- 发布后必须在飞书统一登录态确认资产库显示“资产目录已同步”，且没有共享目录降级警告。
