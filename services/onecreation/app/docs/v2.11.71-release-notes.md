# v2.11.71 发布说明

发布日期：2026-09-03

## 一键做同款：任务列表与分步工作区

- 进入“一键做同款”后默认先展示任务列表，历史任务可直接恢复，新任务可在原任务后台运行时并发创建。
- 打开或新建任务后进入左右分栏工作区：左侧展示“提交成功画布、源画布拆解、确认上游资产、同款结果输出”四个阶段，右侧展示当前阶段内容。
- 步骤会随任务状态自动切换；已完成阶段显示绿色，进行中阶段高亮，失败或中断阶段显示红色，未开始阶段保持灰色。
- 支持点击已完成阶段回看内容，并可通过“返回任务列表”回到任务首页。
- 移除旧版“复刻边界”说明卡片，释放内容区宽度，并补充桌面端与窄屏响应式布局。
