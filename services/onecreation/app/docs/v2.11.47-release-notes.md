# v2.11.47 发布说明

## 一创制作：一键做同款

- 在中枢平台“一创制作”新增第 5 个板块“一键做同款”，支持从成功 LibTV 画布 URL 与 TaskID 拆解视频节点、提示词、参数和全部上游资产。
- 正式开放六类复刻：仅换产品、仅换口播、换产品 + 口播、仅换背景、换人物、换背景 + 产品。
- 换产品时调用平台内置产品资料和 OSS 产品图库；换背景或人物时支持上传 1–3 张目标参考图与补充说明。
- Qwen 3.7 Plus 负责产品、背景、人物承载图审计及生图/视频提示词最小编译；GPT Image 2 失败时自动回退 Seedream 5.0 Pro。
- 上游图需要重建时先生成双候选并等待人工确认；确认前不创建 LibTV 视频节点。
- 新画布沿用源节点模型、模式、时长、清晰度、高级参数和输入顺序，并把源引用与新增背景/人物逻辑引用映射为真实 nodeKey。

## 历史同款与提示词库

- 成功任务以卡片进入历史任务，可直接再次“做同款”，不必重复填写源画布 URL 和 TaskID。
- 正式案例 JSON 快照同步 OSS，结构化索引写入素材中心 MySQL；页面支持关键词、SKU、复刻类型、视频类型、模型、TaskID 和日期检索。
- OSS 或数据库暂不可用时保留本机回退缓存，任务和案例继续按当前工作台账号隔离。
