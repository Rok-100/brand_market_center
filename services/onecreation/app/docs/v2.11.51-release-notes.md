# v2.11.51 发布说明

## 修复

- 修复中枢 OA 登录用户打开产品资产库时，共享资产目录被旧部门 OpenAPI 拒绝的问题。
- 已通过中枢校验的请求改由部门协作服务 API Key 完成服务间认证，不再向旧接口转发其无法识别的 OA 用户令牌。
- 保留旧工作台登录票据的兼容路径，未通过外层中枢校验的 OA 请求仍会被拒绝。
- 将部门协作服务返回的嵌套错误转换为可读文本，避免页面显示 `[object Object]`。

## 验证

- 覆盖旧工作台票据、中枢 OA、未校验 OA 和结构化错误四类回归场景。
- 发布前运行共享资产专项测试、完整测试和生产流水线检查。
