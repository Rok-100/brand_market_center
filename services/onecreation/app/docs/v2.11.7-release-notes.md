# v2.11.7 发布说明

## 本次更新

- 备用创意通道的产品白底图选择结果改为与备用半自动通道一致的双列大图展示，统一图片序号、已选数量和调整选择入口。
- 一句话自然指令使用完整输入框直接编辑；仅在内容溢出时出现纵向滚动，减少嵌套边框并保持四列布局一致。
- 修复 `workbench-task-v2` 在任务执行阶段被二次标准化为旧 `per-job` 模式的问题。
- 备用创意通道提交当前任务中心的任务 ID，由服务端读取可信任务名称和创建时间；新生成任务按统一项目与画布规则执行。

## 项目与画布规则

- 项目名称：`备用创意通道工作台-电脑-设备后8位`。
- 画布名称：`YYYY-MM-DD-任务中心任务名称`。
- 同一任务多次生成或一次生成多条视频时复用同一画布，并在画布内创建多个视频节点。
- 不同任务、不同账号、不同电脑及不同业务模块继续独立隔离。
- 已绑定旧项目或旧画布的历史任务保持原位置，不进行破坏性迁移。

## 验证

- 备用创意通道产品图展示、自然指令输入与任务上下文传递测试通过。
- 工作台项目与画布命名、同任务复用及跨任务隔离测试通过。
- 仓库完整自动测试通过。
- 发布过程不发起正式视频生成，不消耗 LibTV 视频额度。
