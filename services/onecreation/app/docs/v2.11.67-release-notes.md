# v2.11.67 发布说明

发布日期：2026-09-01

## 一键做同款：共享上游与参数冲突修复

- 同一任务画布并发生成多个 SKU 时，未替换的同一源素材只下载、上传一次，各视频节点直接连接同一个共享 `nodeKey`。
- 相同背景或人物参考按任务画布复用；目标 SKU 专属候选图继续按目标隔离，避免跨 SKU 误用。
- 共享上传使用单飞锁；并发分支等待同一个上传结果，失败后释放锁并允许后续重试。
- 源节点参数按“顶层参数 < `settings` < `advancedSettings`”合并，同名 `-s key=value` 只输出一次，修复 `key [ratio] 重复出现` 导致的视频节点创建失败。
- 上传前即进入“上传上游资产”状态，上传或审核失败时不再误显示为“准备任务共享画布”。

## 发布门禁

- 双 SKU 并发回归确认共享素材只上传一次，两个视频节点均通过 `--left` 连接同一 `nodeKey`。
- 参数迁移回归覆盖生产冲突结构，确认 `ratio`、`resolution`、`duration`、`enableSound` 均只输出一次且采用当前 `settings` 值。
- 专项测试、完整测试、核心脚本语法检查及 `git diff --check` 必须通过。
- 生产流水线继续执行备份、候选镜像构建、服务器端测试、服务就绪和线上版本检查。
- 线上验收只核对 v2.11.67 与静态资源版本，不自动重试失败任务，不创建 LibTV 节点，不消耗图片或视频生成额度。
