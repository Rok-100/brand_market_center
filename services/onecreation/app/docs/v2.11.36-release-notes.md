# v2.11.36 发布说明

## 一键换品 ShotPlan 排版与候选切换

- 原片分析区改为 ShotPlan 上方的全宽紧凑栏，默认收起，只保留分析状态和“查看原片分析”按钮；展开后仍可查看全部只读指标和深度拆解。
- ShotPlan 内的“关键状态”和“生成结果”改为约 40:60 的左右布局，窄屏自动恢复上下布局；标题、正文、状态和按钮字号同步放大。
- 新关键帧候选改为 Tab 展示。单张重新生成继续保留旧候选，并自动切换到最新 Tab；人工选用、删除、依赖失效与生成门禁保持不变。

## 一键换品失败后切换模型重生成

- 上一批视频明确为失败或中断时，允许用户切换视频模型，并按新模型的时长、参考图数量和媒体能力重新规划 ShotPlan。
- 原失败任务 ID 会归档到 `generatedJobHistory`，原成片记录和 LibTV 画布继续保留；当前任务解除旧批次绑定后，可重新确认 ShotPlan、生成关键帧并再次提交。
- 运行中、成功或待复核批次仍禁止切换模型重规划，避免重复提交或覆盖有效结果。

## 7 款产品统一资料卡

- 将 `20260824视频平台7款产品资料入库.xlsx` 的已复核内容转换为 `app/assets/product-workflows-runtime/product-profiles.json`，统一管理 7 个精确产品 ID 的正式名、平台名、简称、规格、包装层级、尺寸、状态和负向约束。
- 新增结构化 `scaleReference` 和 `quantityStrategy`。首帧、关键帧、视频提示词、成片验收、AI 产品镜及备用创意通道都读取同一资料版本。
- 多件抱持、堆叠和陈列不再机械保留旧件数；系统按新品真实尺寸保持原画面的占用区域、重心、遮挡、密度和承托关系。深海次抛明确支持把 4 列×2 行共 8 个小瓶重构为 2 列×2 行共 4 个零售盒。

## 产品身份与契约修正

- 晶润紧致眼膜继续使用平台名称 `WIS晶润紧致眼膜 3.0` 和规格 `1.3g×60片`；外盒正面为 8×4.4cm，深 8cm，顶部/底部为 8×8cm。
- 燕窝胜肽焕润面膜锁定 50g；外盒 5.4×5.4×高 8.2cm，圆罐直径 4.9cm、高 7.8cm。
- `wis-whitening-ampoule` 沿用既有产品 ID；正式产品名为 `+WIS+ 光感微珠美白精华液`，平台名称为 `WIS美白针`，平台简称为 `美白针`，没有新建其他产品。
- 7 款产品均具备一键换品执行契约；深海次抛开启方式统一为侧向掰断帽盖，不再允许旋拧或剪开。

## 资料来源收敛

- 旧的黑晶面膜、晶润眼膜和燕窝面膜 3 个本地 MD 已删除。
