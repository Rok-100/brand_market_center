# v2.11.80 发布说明

发布日期：2026-09-03

## 一键做同款：产品关键帧漏检复核

- 后台仅对存在矛盾信号的负向关键帧执行 Qwen 3.7 Plus 单帧高清二次识别，并以源 SKU 图片辅助身份比对。
- 小产品、手部遮挡、袋口/盒口和画面边缘成为二审重点；二审返回产品像素证据与位置，结果作为人工预选而非最终强制结论。
- 产品变更任务的图片统一提供“需要换品 / 直接复用”两个选项；同时换人物或背景时使用“不含原产品”，避免处理结果歧义。
- 人工选择立即保存且优先于模型；已进入映射阶段的任务同步重算全部目标 SKU 映射，修正结果也写回历史源模板快照。
- 更新一键做同款静态资源缓存版本为 v2.11.80。
