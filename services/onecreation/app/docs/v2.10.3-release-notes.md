# v2.10.3 发布说明

## FanDo 授权文件选择修复

- 首次导入改用普通文件上传控件，不再通过 File System Access API 申请 `%APPDATA%` 敏感系统目录的持久访问权限。
- 自动复制内容改为 `%APPDATA%\FanDo\openclaw` 文件夹路径，粘贴并回车后进入目录，再选择 `openclaw.json`，避免完整文件路径被系统直接打开。
- 已保存且仍可用的历史文件句柄继续支持一键重新读取；句柄对应文件被移动或删除时，会明确引导用户重新选择。

## 授权验证与安全

- 浏览器只解析并提交 API Key，不上传整个 `openclaw.json` 文件。
- 导入后继续执行只读最小探针，探针通过后才按当前飞书用户加密保存凭证。
- 不涉及数据库迁移，原有任务、素材、LibTV 绑定和已保存的个人 FanDo 授权保持不变。
