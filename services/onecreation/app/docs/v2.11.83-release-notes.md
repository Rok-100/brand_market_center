# v2.11.83 发布说明

## 一键做同款：动作冲突自动补全

- 阶段 03 针对每个存在动作冲突的源节点，独立组合源图、源产品识别、目标 SKU 资料、当前所选 OSS 产品身份图、形态与动作冲突、原视频节点提示词，自动生成可执行的冲突解决方案。
- 自动方案只改产品相关持法、接触方式、朝向和专属操作；人物身份、未参与持物的手、其他道具、表情、视线、对白、镜头、构图、背景、剧情顺序与节奏保持不变。
- 模型不可用或返回无效结果时自动使用确定性规则草稿，输入框不再留空；用户可以直接编辑微调，后续生图严格使用最终提交文字。
- 用户切换 OSS 产品图但没有修改自动草稿时，服务端按新选择刷新规则草稿；用户已编辑时保留人工内容，并标记为用户微调版本。
- 页面新增形态/动作冲突摘要、草稿来源和“可编辑”提示，明确当前为什么高风险、系统已处理什么以及最终以哪段文字执行。
