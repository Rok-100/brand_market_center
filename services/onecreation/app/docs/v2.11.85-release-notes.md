# v2.11.85 发布说明

发布日期：2026-09-04

## 一键做同款：上游资产确认与候选图工作流

- 将购物袋、箱子、篮子、托盘、抽屉、收纳盒等实际装取产品的对象统一识别为“承载道具”；仅在可靠判断目标 SKU 大于可用容积时提示用户选择保留道具并改写动作，或让道具与产品联动重构。
- 阶段 03 隐藏原图复用及目标 SKU 原图直连资产的拆解正文，保留处理标签；需重构或存在审计冲突的资产继续显示必要说明。
- 单个上游画面的候选生图上限由两轮提升为三轮，每轮继续生成两张并保留此前全部候选；第四轮由服务端门禁阻止。
- 每个需重构资产组新增“用户自定义上传”，支持 PNG、JPG、JPEG、WEBP，单图不超过 10MB；上传图经任务作用域校验后固化到任务目录并默认选中，用户仍可改选任意候选图。
- 首页左下角开发者署名已隐藏，右侧使用说明继续保留。
- 一键做同款静态资源缓存版本更新为 v2.11.85。
