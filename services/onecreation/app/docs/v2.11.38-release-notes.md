# v2.11.38 发布说明

发布日期：2026-08-25

## 一键换品参考视频 ASR 与口播编排

- 参考视频分析并行调用 SiliconFlow `XingChenAGI/XingChenASR-Diarize-V3.0`，服务端通过 `XingChenASR` 环境变量读取共享密钥。密钥不进入浏览器、接口响应或仓库。
- 原片口播以可编辑文本框展示计时字符数；模型返回说话人分段时，页面同时展示说话人、起止时间和分段文本。双人音频可从 16kHz 单声道音轨识别，说话人标签以模型实际返回为准。
- “只换产品”默认沿用旧口播，生成画面与原片对应音轨重新合成；“只换口播”和“产品+口播”默认使用新口播。
- 新口播先由 ASR 原文预填；“产品+口播”再由 Qwen 3.7 Plus 严格依据 `product-profiles.json` 预替换产品名称和卖点，并以红色差异提示用户。
- 用户确认新口播后才编译 ShotPlan。确认后的目标时长统一按 `原片时长 × 新口播计时字符 ÷ 原口播计时字符` 计算，计时字符为去除空白后的 Unicode 字符数，标点参与计数。
- 服务器会按目标总时长和视频模型单段限制拆分/分配生成单元；新口播被修改后，既有锁定稿和 ShotPlan 自动失效，必须重新确认。

## 发布配置

- Gitea Actions 仓库 Secret：`XingChenASR`。
- 运行环境变量：`XingChenASR`。
- 默认模型：`XingChenAGI/XingChenASR-Diarize-V3.0`。
- 默认接口：`https://api.siliconflow.cn/v1/audio/transcriptions`。
