# v2.11.35 发布说明

## 一创创作接入中枢

- 将 AI一创工作台整理为 6 个可直接使用的功能区：自动化Allive、视频产品替换、KOC 15秒桌拍视频、视频背景替换、竞对视频复刻裂变、视频提示词逆推。
- 视频产品替换与视频背景替换共用成熟的一键换品引擎，但由入口参数安全预选真实执行模式；新入口不会覆盖正在进行或历史任务。
- KOC 与竞对裂变入口增加新任务预设，保留原有草稿、任务、资产与人工确认流程。

## 视频提示词逆推

- 新增独立的分析任务页，支持大文件分片上传、逐镜多模态分析、历史任务恢复、母提示词与负面提示词复制、完整 Markdown 文档下载。
- 逆推流程只调用 Qwen 多模态分析，不创建 LibTV 画布、节点或视频生成任务。
- 输出严格保留证据边界；无法核验的商品身份、功效、价格、规格、赠品与材质不会被补写。

## 中枢权限

- 工作台在自身签名登录成功后，通过受保护的服务接口重新读取中枢实时登录白名单和 `ai-first-creation` 界面权限。
- 权限失败时服务端拒绝业务 API 和受保护页面；权限中心异常时失败关闭，不放行绕过。
- 权限结果仅短缓存 15 秒，兼顾实时撤权与页面请求性能。
