## 发布内容

- “新增正式案例”在原有人工质检通过成片之外，新增完整成功拆解模板候选。
- 成功拆解模板必须同时具备源视频、完整源提示词、OSS 快照和 MySQL 索引，普通拆解记录不会自动进入提示词库。
- 归属人只能加入自己的模板，实名管理员可跨归属加入；管理员代操作不会改变案例归属。

- 使用确定性正式案例 ID 防止重复入库；删除正式副本时继续保留原历史模板。
- 前端候选列表明确区分“成功拆解模板”和“质检通过成片”。
