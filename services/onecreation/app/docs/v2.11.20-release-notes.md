# v2.11.20 发布说明

## 一键换品人物复核路由修复

- 人物主要身份证据不足不再单独把任务升级为 T4，也不再用最低人物置信度把可执行任务压成“人工复核”。
- 多人物、多场景和硬切视频继续按独立 `sourceShot` 保留人物、服装、发型、背景与动作差异，使用 T2 `source_hard_cut_preservation` 质检。
- 无人脸、仅手部出镜的连续产品状态链可以按产品物理状态进入 T3，不再因缺少脸部证据被人物规则阻断。
- 性别相同仍不能作为同一人物依据；身份主要证据不足只禁止跨镜头自动合并人物，不代表视频无用。

## T4 保留边界

- 双机位、多视角、分屏、手部数量/透视冲突、模型硬限制，以及明确无法消解的跨镜头人物、状态或透视冲突仍进入 T4。
- 规则快照升级为 `replacement-t1-t4-v2`。服务启动时会自动重算 v1 历史任务，解除仅由人物证据不足造成的旧 T4 阻断，无需重新上传原片或重做关键帧。

## 验证

- T1—T4 专项测试新增真实缺陷回归：低人物证据单镜头、四镜头多人物硬切、仅手部 T3、真实复杂 T4、旧任务迁移。
- 发布前运行一键换品相邻专项测试与完整测试。
