# v2.11.107 发布说明

## 发布内容

- “仅换背景”支持用户上传 1 张完整新首帧，并直接替换源首帧 `nodeKey`。
- 上传首帧不再作为额外背景参考，不新增 `ref-background-*` 节点，也不调用 Qwen、GPT Image 2、Seedream 或 OpenCV。
- 最终视频继续按源画布输入顺序映射资产，并保留源视频模型、模式、时长、比例、清晰度和高级参数。
- 已卡在 3% 的历史上传任务在服务恢复后自动迁移到首帧直替路径，清理旧候选并停止旧生图流程。
- “仅换背景”同时支持平台生成纯背景候选：每轮并发生成 2 张、最多 2 轮，保留历史候选并在人工确认后重建首帧。
- 发布脚本会在切换前按精确 Compose 项目与服务标签清理同一服务的遗留副本，保留当前正式容器，避免历史重命名容器争抢固定生产名称。
