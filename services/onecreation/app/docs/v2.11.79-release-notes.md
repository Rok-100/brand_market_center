# v2.11.79 发布说明

发布日期：2026-09-03

## 一键做同款：成片自动找回与任务标题操作

- 服务启动后自动扫描已提交视频节点但尚未完成平台回传的任务，并按原画布、确定性节点名回查已有成片。
- 恢复过程只查询、下载和回传现有视频，不创建新节点，也不重新发起视频生成。
- 回查失败时按退避策略持续重试；服务或上游恢复后，无需用户停留在任务页面即可自动补回。
- 后续轮次失败时仍展示此前已成功回传的视频，避免已有成片被失败状态隐藏。
- 任务标题左侧显示向左的编辑笔，标题右侧新增复制按钮；支持安全剪贴板，并在标签页失焦或权限受限时自动切换兼容复制。
- 更新一键做同款静态资源缓存版本为 v2.11.79。
