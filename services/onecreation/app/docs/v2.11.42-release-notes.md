# v2.11.42 发布说明

## 单视频批量裂变任务生命周期

- 未提交草稿改为按任务ID分别保存；新建任务不会读取其他任务的母版、裂变方向或图片资产。
- 切换任务时按服务端记录完整回填该任务的母版视频、三级数量、允许变化维度、产品设置、补充要求和参考图片。
- 任务提交分析后锁定母版、裂变方向和图片资产，防止运行中的生成快照被前端修改。
- 已有成片的任务在详情页第 05 步提供“修改任务并生成新版本”。左侧任务栏只展示“修改中”等状态，不承载版本修改操作；用户必须先确认“本任务已成功生成视频，如修改则可能影响历史记录”，提交后沿用原任务编号并进入下一轮分析与生成。
- 二次生成前自动归档上一轮所有当前成片和单条重生历史；历史成片可在页面内预览与下载，不被新一轮覆盖。
- 同一任务的第二轮及后续 LibTV 节点增加轮次标识，避免和上一轮母版、图片、视频及质检节点重名。

## 暂不包含

- 本版本没有改变单视频裂变的 LibTV 团队、项目或画布归属规则。
- 团队共享项目规则需产品确认后另行修改与验证。

## 验证

- 新增任务草稿隔离、任务回填、生成锁定、风险确认、二次生成归档及历史成片入口测试。
- 自动化验证不创建 LibTV 项目、画布或视频节点，不消耗生成额度。
