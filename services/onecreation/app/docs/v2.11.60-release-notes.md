# v2.11.60 发布说明

## 功能内容

- 视频平台首页制作入口由 5 个收敛为 3 个，按 `01 AI产品镜`、`02 一键做同款`、`03 AI KOC` 排列。
- 一键换品和单视频批量裂变保留代码、路由、任务进度绑定和权限键，但默认隐藏，可在后续权限与产品开发中重新开放。
- 制作入口可见性由统一配置控制，静态页面同时保留 `hidden` 与 `aria-hidden` 安全兜底。
- 首页整体切换为与 WIS 中枢一致的蓝白色调，制作入口卡片、标题、说明、编号、图标和操作文字约放大 20%。
- 桌面端三卡同排，窄屏自动降为双列或单列，并移除一键做同款旧有跨整行样式。

## 验证口径

- 桌面端三卡同排且等宽等高，窄屏无横向溢出；控制台无 error 或 warning。
- 入口专项 36/36、完整回归 682/682 通过，`git diff --check` 无错误；部署后独立核对生产版本、服务器发布检查与登录态页面。
