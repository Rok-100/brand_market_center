# v2.11.86 发布说明

发布日期：2026-09-04

## 一键做同款：管理员修改历史模板归属

- 历史任务卡片的“归属”旁新增管理员专属“修改归属”入口，通过选择框把模板转移给已登录过工作台的有效用户。
- 普通用户不获取归属候选列表；服务端同时校验实名管理员白名单、目标用户绑定和模板存在性，不信任前端提交的姓名。
- 归属变更仅改变历史模板可见范围，不迁移或修改原任务，也不覆盖原始创建人 `createdBy`。
- 案例保存当前归属名称、修改人、修改时间及最近 20 条归属变更记录。
- 修改后重建不可变 JSON 快照，将 OSS 对象迁入新归属目录，更新数据库 `owner_key` 与检索索引，并在同步成功后清理旧 OSS 快照。
- 一键做同款静态资源缓存版本更新为 v2.11.86。
