# v2.11.57 发布说明

## 修复内容

- 修复飞书统一登录用户读取共享资产时，中枢 `/api/team-workbench` 请求被登录网关以 HTTP 302 重定向的问题。
- 仅在 OA 令牌已经通过工作台外层中枢校验后，将浏览器已有的同域中枢会话 Cookie 转发给固定的中枢网关。
- 转发前剔除本地 `fandao_ai_workbench_session` 和旧 `suda-csrf-token`，避免把工作台票据带到中枢；写请求继续使用本次服务端生成的 CSRF Cookie。
- 保留 v2.11.56 的安全响应诊断，后续异常仍会显示 HTTP 状态而不泄露凭证值。

## 验证口径

- 飞书中枢登录后直接打开一创资产库，无需再次登录 OSS。
- 页面显示“资产目录已同步”，不再显示共享资产 HTTP 302 警告。
- 本地工作台票据链路仍走旧 OpenAPI，并继续只转发签名工作台票据。
