# v2.11.97 发布说明

发布日期：2026-09-07

## 一键做同款成片人工质检

- 每一轮视频生成、下载并完成 AI 参考检查后暂停在 `awaiting_manual_review`，由用户在大视频窗口中人工判断成片是否符合要求。
- 第一轮符合要求时可直接“符合要求并归档”，任务与目标状态切换为成功，页面显示“已完成”，不再生成第二轮。
- 第一轮不符合要求时，用户填写人工意见后才生成第二轮；第二轮仍需人工质检，如仍不符合则保留两轮结果并阻断第三轮。
- 只有人工审核通过的轮次进入正式提示词案例库；归档记录保留所选轮次与人工审核信息。
- 新增任务级人工质检接口，并为人工触发第二轮、归档及服务重启补充检查点恢复，避免重复生成或丢失待审核状态。
