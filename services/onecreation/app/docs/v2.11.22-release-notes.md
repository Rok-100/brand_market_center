# v2.11.22 发布说明

## AI-KOC LibTV 提示词节点绑定修复

- 视频分镜提交前，人物场景图、产品图、参考音频和原片参考等命名节点统一解析为当前任务画布中的实际 `nodeKey`。
- 保存到任务 JSON、提示词包并提交给 LibTV 的运行时提示词使用同一份 nodeKey 版本，避免 LibTV 读取节点时自动把命名占位符标准化为 nodeKey 后产生伪差异。
- 如果提示词仍含未解析的命名节点，系统会在创建视频节点前停止，并直接指出缺少绑定的节点名称。
- 严格核验规则没有放宽：仍然只归一化 CRLF/LF 换行，其他字符差异继续阻止整批视频生成。
- 已在提示词核验阶段失败的 AI-KOC 历史任务可使用原有“重新生成本条”或“重新生成全部失败分镜”入口原地恢复，不重做已完成的深拆、候选图、资产上传和审核。
