# v2.11.58 发布说明

## 修复内容

- 将视频平台调用中枢工作站身份授权接口的默认等待上限由 8 秒调整为 30 秒。
- 新增服务端环境变量 `WIS_CENTRAL_ACCESS_TIMEOUT_MS`；未配置时默认使用 `30000` 毫秒。
- `/api/ready` 的 `centralAccess` 状态新增 `timeoutSeconds`，用于发布后核实实际生效值。
- 保持原安全边界：超时后仍拒绝业务访问，不跳过中枢权限校验，也不放宽模块授权。

## 验证口径

- 默认配置下，`centralAccess.timeoutSeconds` 返回 `30`。
- 显式配置其他毫秒值时，状态秒数与配置一致。
- 飞书统一身份有效时，视频平台最多等待 30 秒获取中枢权限结果。

## 发布结果

- PR #249 已合并为 `89f73334d130d8c9f4c444c9aea0d7985d98b76c`。
- 生产流水线 #260 执行成功，发布版本为 v2.11.58。
- 登录态线上复验约 21 秒进入资产库，超过旧 8 秒且低于新 30 秒，确认视频平台不再在 8 秒时提前拒绝访问。
- 资产库仍提示共享资产目录请求为 HTTP 302，并回退显示本机缓存；这是进入平台后的部门协作接口问题，与中枢身份授权等待上限分属不同链路。
