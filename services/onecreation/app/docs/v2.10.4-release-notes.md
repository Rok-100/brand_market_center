# v2.10.4 发布说明

## 个人 FanDo 凭证目录权限修复

- 个人模型凭证的线上持久化目录从不可写的 `/data/provider-credentials` 调整为 `/data/home/.workbench/provider-credentials`。
- 新目录位于现有的 `runtime-data/home` 挂载中，容器的非 root 运行用户可以创建和写入，重新构建或升级容器不会清除凭证。
- 主工作台和明星画面服务继续使用同一凭证目录，按飞书用户隔离并使用 AES-256-GCM 加密保存。

## 兼容性

- 不涉及数据库迁移，不修改任务、素材、成片或 LibTV 个人绑定。
- 保留 v2.10.3 的普通文件上传与最小可用性探针流程。
