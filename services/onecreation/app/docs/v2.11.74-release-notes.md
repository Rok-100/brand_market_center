# v2.11.74 发布说明

发布日期：2026-09-03

## 一键做同款：上游资产确认体验与视觉识别

- 固定任务工作区顶部工具栏，并同步调整左侧流程栏吸顶位置，切换 Stage 和滚动长列表时任务状态始终可见。
- 将完整上游资产清单整理为带表头的语义化表格，提升资产名称、nodeKey、处理方式和约束说明的字号与可读性。
- 修复当前流程步骤悬浮时出现浅色背景配白字的问题，进行中步骤始终保持稳定高亮。
- 新增原视频视觉理解：抽取代表帧，与各 SKU 的分层真值图比较，展示候选、相似度、匹配层级、视觉证据与不确定项；视觉结论保留人工确认门禁。
- 勾选产品内部素材图时自动勾选外层产品；取消最后一张素材图或切换形态清空素材时同步取消外层选择。
- 产品较多时显示底部常驻操作栏，实时汇总已选产品和素材数量，无需滚到列表末尾即可生成映射。

- 核心 JavaScript 语法、差异格式检查和完整串行回归必须通过。
