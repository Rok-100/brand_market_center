# v2.11.6 发布说明

## AI-KOC 任务持久化

- 点击“新建任务”时立即在服务端创建独立草稿。空白任务也会进入当前账号的任务中心并保持固定位置，不再因刷新、切换任务或关闭页面而消失。
- 删除任务仍只接受任务卡片右上角的人工删除操作；系统不会自动清理空白草稿或已填写草稿。
- 表单字段、旧口播、新口播、原片、人物图和产品图均绑定到当前任务；输入采用防抖自动保存，离开页面时再执行一次保底同步。

## 任务恢复与提交

- 重新打开草稿或历史任务时，从服务端 `job.config` 恢复全部表单字段和上传素材，不再只显示空表单。
- 草稿提交原片拆解时沿用相同任务 ID、用户自定义名称、创建时间和固定排序，不创建重复历史任务。
- 保留本地草稿作为断网与旧版本迁移兜底，但服务端任务记录是任务持久化的唯一事实来源。

## 验证

- 新增 AI-KOC 服务端空草稿、逐项自动保存、离页保底保存、历史任务回填和原任务 ID 提交回归测试。
- 更新版本与页面缓存标识为 v2.11.6。
