# v2.11.2 发布说明

## 新增

- AI产品镜新增第三个“备用创意通道”，页面大标题为“一句话自然指令输出创意视频”。
- 输入支持可选自定义场景图、必选1–9张产品白底图、一句话自然指令；输出为创意视频。
- 提供8个商业分类的轮播单选入口，每类包含20个服务端场景预设。
- 生成数量支持1–9；同一任务复用一个独立LibTV画布，每套不同提示词创建一个视频节点。

## 服务端与隔离

- 新增 `creative_instruction_showcase` 工作流和独立API命名空间。
- 新增版本化的8×20场景库、提示词编译器、显式分镜解析、产品身份约束和黑晶面膜SKU规则。
- 新通道独立维护前端表单、上传队列、草稿缓存、运行状态、LibTV模块、轮询和结果映射。
- 功能开关关闭时不露出新通道，原三路制作与备用半自动通道保持原行为。

## 验证

- 覆盖产品图0/1/9/10张、生成数量0/1/9/10、分类必选、有/无场景图、显式三分镜、多提示词去重和同画布多节点。
- 使用巴厘岛海边落日篝火示例完成无额度编译预览：2套不同提示词，每套保留3个分镜。
- 未在发布前发起正式视频生成或消耗LibTV额度。
