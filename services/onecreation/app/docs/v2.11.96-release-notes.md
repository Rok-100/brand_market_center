# v2.11.96 发布说明

发布日期：2026-09-07

## 一键做同款 OpenCV 数量冲突人工修正

- 阶段 03 在每个含产品的场景图上核对审计观察数量与有效产品实例框数量；不一致或没有可靠实例框时明确阻断，不再把错误配置再次提交给 OpenCV。
- 冲突节点显示观察数量、可靠实例框数量和“重新识别数量与槽位”；已有可靠实例框时同时提供“人工确认按 N 个可靠实例执行”。
- 重新识别仍冲突时继续阻断；人工确认只把该源图数量修正为有效实例框数量，不改变源拆解结果、目标 SKU 或其他节点。
- 映射确认接口和候选资产准备执行前使用相同后端门禁；OpenCV 错误保留源 `nodeKey`、观察数量与可靠实例框数量，便于定位。
- 修正后重建当前目标映射并同步共享审计快照；此前已上线的“重新配置上游资产”恢复流程保持不变。
