# v2.11.77 发布说明

发布日期：2026-09-03

## 一键做同款：历史模板与提示词库体验改进

- 在“历史任务做同款”点击“做同款”后立即创建并进入对应任务，后台继续复用模板画布和编译初始提示词。
- 历史模板支持按 URL、TaskID、模板视频名称搜索并分页浏览。
- 模板归属人可以修改自己的模板名称，实名管理员可以跨归属修改；名称同步写入本地快照、OSS 快照和数据库索引。
- 新任务提交前按标准化画布 URL 和精确 TaskID 检查已收录模板，命中时阻止重复创建并引导用户在历史任务中检索。
- 正式提示词库页面明确入库、筛选和查看原则：只有新视频生成成功、下载完成且自动质检通过的案例入库，仅拆解成功的源模板只进入历史任务。
- 发布链在创意中枢入口文件与当前线上容器完全一致时先执行健康和登录契约校验，再复用现有入口，避免无关版本重复占用全局镜像构建槽。
- 发布链在 OpenCV 几何服务的构建输入、现网运行文件和健康契约均完全一致时复用现网镜像；任一项不一致仍执行完整构建与镜像内单测。
- 更新一键做同款静态资源缓存版本，确保发布后加载 v2.11.77 前端资源。

## 发布门禁

- 一键做同款专项 34/34 通过。
- 完整串行回归 713/713 通过。
- 核心 JavaScript 语法、差异格式与本地浏览器交互核验通过。
- 线上验收只执行版本、服务健康、静态资源和页面只读检查，不创建真实 LibTV 画布或图片/视频生成任务。
