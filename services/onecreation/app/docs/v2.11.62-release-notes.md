# v2.11.62 发布说明

## 功能内容

- 一键做同款目标 SKU 目录合并基础产品与 OSS 资产管理中的启用有图产品；原片为燕窝面膜时可选目标补齐 `WIS美白针/美白精华液`。
- SKU 产品图取消默认勾选；平台推荐只作提示，用户必须手动选择至少一张，后台同步校验所选资产属于当前 SKU。
- 修复 LibTV CLI 输出含进度文本或 NDJSON 时被误判为非法 JSON；响应解析失败时按画布与精确节点名回查，重试优先恢复既有节点，避免重复生成。
- 任务进入生成、成功或失败终态后，前端持续显示紧凑的 `03 确认上游资产` 摘要，明确目标 SKU、节点映射、OSS 直连、候选核实和最终确认数量。

## 验证口径

- OSS 管理中的有图 SKU 会进入目录，零图占位 SKU 会被排除；燕窝面膜原片应显示 6 个可选目标并包含 `WIS美白针`。
- 切换 SKU 或展示形态后所有产品图均保持未勾选，未手动选择产品资产时后台拒绝进入下一步。
- 纯 JSON、带进度文本 JSON 与 NDJSON 均能解析；失败任务可恢复上一视频节点且不会重复执行 `node create --run`。
- 一键做同款主流程、治理与产品映射联合专项 27/27，完整串行回归 685/685 通过；核心脚本语法检查与 `git diff --check` 通过。
