# v2.11.23 发布说明

## 一键换品视频节点内镜头语义合并

- 用户继续使用“与上一个镜头共用关键帧”操作；系统不再只共享锚点，而是生成真正的 `Merged Generation Unit` 与 `Anchor Group`。
- 合并后重新编译 `Normalized Action Timeline`、`Product State Chain`、`Person Continuity Profile`、`Asset Manifest`、`Compiled Video Prompt v2` 和 `QA Contract`。
- 原始 `sourceShots` 事实层保持不变；取消共用后按事实层重建独立生成单元，可逆恢复关键帧建议和执行契约。
- 前端显示连续生成组及动作、人物、产品重算摘要；原有“调整关键帧”和“确认并生成”流程保持不变。
- 参考视频、产品白底图、关键帧和纯语义时间帧按独立资产角色与权威优先级编译；只有实际模型资产连接 Video Node，纯语义时间帧只参与时间轴定位。
- 旧 ShotPlan 和现有 Generation Prompt 自动迁移到兼容结构；未选择共用关键帧的任务继续使用独立生成路径。

## 安全与发布边界

- T1—T4 执行分类继续生效；明确人物或产品冲突会阻止不安全合并，T4 仍需人工复核。
- 视频提交前校验源镜头覆盖、动作时间轴、人物与产品连续性、锚点连接、素材上限和提示词资产引用。
- 发布验证只执行自动化测试、健康检查和只读页面/API 核验，不创建正式 LibTV 视频任务，不消耗视频额度。
