# v2.11.70 发布说明

发布日期：2026-09-02

## AI产品镜：创意通道指令示例

- “备用创意通道 / 输入 3 · 一句话自然指令”展示新的完整案例文案，帮助用户先选创意视频分类，再按场景、动作、分镜和特殊要求组织指令。
- 新增“复制示例”按钮，复制动作只写入剪贴板，不会把示例写入用户输入值、草稿或生成请求。
- 输入框获得焦点或已有用户内容时自动隐藏示例，保留原有输入、编辑和滚动能力。
- 更新创意通道脚本和共享样式的静态资源版本参数，避免线上缓存错配。

## 发布门禁

- 创意通道专项测试覆盖文案、复制入口、输入值隔离、提示层交互和静态资源版本。

- 线上验收只执行版本、服务健康、静态资源和页面只读检查，不发起图片或视频生成，不消耗模型额度。
