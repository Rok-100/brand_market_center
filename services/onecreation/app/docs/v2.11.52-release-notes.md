# v2.11.52 发布说明

## 一键做同款：源提示词复制与目标提示词编辑

- “查看源视频原始提示词”新增复制按钮，支持安全上下文剪贴板与旧浏览器回退复制。
- 每个目标 SKU 的视频生成提示词编辑区自动预填溯源得到的原始提示词；多 SKU 可以分别修改，互不覆盖。
- Qwen 3.7 Plus 以用户确认的目标提示词底稿执行产品、口播、背景或人物的最小改写，不覆盖不可变的源提示词快照。
- 候选资产确认页新增最终视频提示词编辑框，用户可以在提交 LibTV 前完成最后修改。
- 后台校验最终提示词非空、新增背景或人物 `nodeKey` 引用仍存在，并逐字保留锁定的新口播；校验失败时不启动视频生成。
- 正式案例同时记录源文本、用户底稿、编译基线和最终确认文本，便于后续检索与复用。

## 兼容与安全

- 旧客户端未提交新字段时继续回退使用源提示词和后台编译结果。
- 用户编辑只影响目标视频提示词，不改变源画布参数、上游资产顺序、模型、模式和高级设置。
- 自动化测试使用假 LibTV、Qwen 和生图依赖，不创建真实视频任务或消耗生成额度。
