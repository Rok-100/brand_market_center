# 品牌营销部工作站

品牌营销部工作站是一套面向文案创作、一创制作和二创混剪的内部工具。本仓库保存当前完整可维护源码，运行任务、上传素材、账号凭证和线上数据库不进入代码仓库。

## 当前版本

- 工作台版本：v2.11.39
- 主分支：`main`
- 线上运行目录与本仓库相互独立；修改源码不会直接影响线上工作站

## 本地启动

1. 复制 `.env.example` 为 `.env`，仅在本机填写配置。
2. 进入 `app` 目录运行 `node server.js`。
3. 浏览器打开 `http://127.0.0.1:3766`。

密钥、登录配置、上传视频、生成结果和缓存禁止提交。
