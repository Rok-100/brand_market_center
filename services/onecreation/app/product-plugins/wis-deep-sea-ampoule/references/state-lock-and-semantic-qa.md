## 已确认的资产状态差异

内置图片不是同一姿态的八个等价参考，必须按状态路由：

| 资产 | 可证明 | 不能证明 |
|---|---|---|
| `package-fully-open.png` | 盒内六个五支联排的数量和盒内姿态；从正面看蓝色标签尾端位于上方 | 联排离盒后的正立展示姿态 |
| `ampoule-strip-5.png` | 正立五支联排；掰断口在上、中段液体舱居中、蓝色标签尾端在下 | 联排仍在盒内的姿态 |
| `ampoule-single.png` | 正立、闭合单支的完整外观 | 已开口、倒置挤压或斜向贴脸姿态 |
| `ampoule-opened.jpg` | 正立单支的开口结构、完整蓝色标签尾端和独立断帽 | 倒置挤压或斜向贴脸时的完整轮廓；图中手模也不是生产手模真值 |

`package-fully-open.png` 与 `ampoule-strip-5.png` 的上下方向不同，不得把二者描述成“同一朝向自然抽出”。`ampoule-single.png` 和 `ampoule-opened.jpg` 都是正立图，不能单独硬锁倒置或贴脸运动。

## 连排方向状态机

使用以下状态名，不用“让标签朝镜头”代替上下方向：

```text
STRIP.IN_BOX
  = 仍在零售盒中，保持 package-fully-open.png 的上下关系

STRIP.EXTRACTING
  = 从盒内平移抽出；上下、正反、抓握点全部继承 STRIP.IN_BOX

STRIP.OUT_SAME_ORIENTATION
  = 完全离盒并停稳；仍保持盒内上下关系

STRIP.UPRIGHT_DISPLAY
  = 掰断口在上、中段液体舱居中、蓝色标签尾端在下，与 ampoule-strip-5.png 一致
```

硬规则：

1. `STRIP.IN_BOX → STRIP.EXTRACTING → STRIP.OUT_SAME_ORIENTATION` 只能平移，禁止同时调转上下、翻正反或换握。
2. 若后续必须进入 `STRIP.UPRIGHT_DISPLAY`，先让联排完全离盒并停稳至少约 0.2 秒，再单独执行一次完整可见的连续旋转；产品全程不得出画，旋转用时建议 0.6–1.0 秒。
3. 一个镜头若时间不足以显示完整旋转，就保持盒内方向，或硬切到新的稳定正立展示镜头；不得用连续画面伪装瞬间翻转。
4. 对相邻关键帧检查四个固定点：掰断口、液体舱、蓝色标签尾端、抓握手指。四者的拓扑顺序不能跳变。

## 单支几何状态机

无论产品怎样旋转或被手遮挡，沿产品长轴的三段顺序必须保持：

```text
开口端/掰断口端 ↔ 中段透明液体舱 ↔ 蓝色标签尾端
```

标准状态：

```text
SINGLE.CLOSED_UPRIGHT
  上：完整圆角矩形掰断口
  中：透明液体舱
  下：刚性矩形蓝色标签尾端

SINGLE.OPEN_UPRIGHT
  上：已打开的细颈管口
  中：透明液体舱
  下：刚性矩形蓝色标签尾端

SINGLE.OPEN_INVERTED
  上：刚性矩形蓝色标签尾端
  中：透明液体舱
  下：已打开的细颈管口

SINGLE.OPEN_DIAGONAL_FACE
  手侧：刚性矩形蓝色标签尾端
  中间：透明液体舱
  皮肤侧：已打开的细颈管口
```

硬规则：

1. 倒置挤压时，蓝色标签尾端必须位于最上方、保持蓝色矩形和原始长宽比；中段透明液体舱位于手指受力处；开口位于最下方。
2. 贴脸短滑时，蓝色标签尾端在手侧、开口在皮肤侧，中段液体舱必须仍存在于二者之间。
3. 拇指和食指只轻挤中段透明液体舱。蓝色标签尾端可以持握，但不得透明化、变尖、变圆、缩短、折弯或被挤瘪。
4. 高风险镜头必须让整支产品轮廓留在画面内，并让至少约三分之一的蓝色标签区域可见；禁止用手指完全遮住管尾后声称外观已锁定。
5. 受压只表现为中段液体舱轻微局部凹陷；开口、细颈、蓝色标签尾端和外轮廓不随压力重建。

## 高风险资产闸门

LibTV 的 mixed reference 是全局参考，不会自动把某张图片绑定到某个分镜。不得因为上传了 `ampoule-single.png` 就声称所有动态单支镜头已被锁定。

执行端到端生成前：

1. 为每个分镜写明 `startState`、`endState`、`orientationState`、`primaryAsset` 和 `requiredExactStateAsset`。
2. `asset_paths` 必须显式填写，优先使用 5–7 张状态匹配资产；不得默认把全部 8 张图无差别接入。
3. 只要出现以下动作，就必须有对应目标姿态的精确资产：倒置已开单支挤液、斜向已开单支贴脸、连排从盒内姿态转为正立姿态。
4. 当前内置资产没有 `SINGLE.OPEN_INVERTED` 和 `SINGLE.OPEN_DIAGONAL_FACE` 的无歧义全身图。若当次 `asset_paths` 未补入这两类状态资产，生成前标记 `asset_gap` 并停止远程提交；可改为不含该动作的安全链，或先制作/补拍状态锚点。
5. 在计划中填写 `required_asset_tokens`；执行脚本必须确认所有 token 都能在文件名或路径中找到，否则在创建 LibTV 工作区前失败。

## 动作预算

以下均视为高风险动作：盒内联排抽取、上下方向旋转、五支分离、断帽、倒置挤液、斜向贴脸。

- 每个高风险镜头只承载一个主要状态变化。
- 不把“分离一支 + 断帽”写在同一镜头。
- 不把“贴脸短滑 + 指腹推开 + 掌压 + 产品终帧”全部压在同一连续动作中。
- 每个高风险动作保留稳定起始和稳定终态，各约 0.2 秒以上。
- 15 秒单节点中，无精确状态锚点时最多安排 2 个高风险动作；超过时必须为每个高风险目标状态提供锚点，或拆成多段生成后剪辑。

## 精华液运动真值

只使用以下口径：

```text
透明无色、低黏度、流速接近精华水。
轻挤中段透明液体舱后，液体从真实开口形成一股短而快速的清透细流。
细流在约 0.2–0.6 秒内触达皮肤并干净断开。
接触手背后立即受重力和皮肤坡度影响，边缘与中心位置持续发生可见位移，迅速摊成低矮、薄而不规则的湿润区。
```

禁止在正向提示中出现：`清晰圆润液滴`、`高凸液滴`、`短暂停留`、`保持原位`、`轻微黏度`、`仅轻微下移`。这些词会把模型推向凝胶行为。

判定失败：

- 液体在管口与手背之间形成长丝并持续超过约 0.5 秒。
- 落到手背后形成规则圆形、高凸胶滴。
- 连续三个约 0.2 秒间隔关键帧中，液滴轮廓和中心位置几乎不变。
- 手指开始推抹前，液体没有任何受重力影响的位移或摊薄。

## 生成前校验

必须逐项通过：

1. 盒内图与离盒联排图是否被标记为不同方向状态。
2. 抽取动作是否只平移，没有同时写“转正、翻面、标签朝镜头”。
3. 目标分镜是否有精确姿态资产，而非仅有同一产品的其他角度。
4. 倒置单支是否明确为“蓝色尾端在上—液体舱居中—开口在下”。
5. 贴脸单支是否明确为“蓝色尾端在手侧—液体舱居中—开口在皮肤侧”。
6. 是否明确只挤中段透明液体舱。
7. 液体正向描述是否只使用“短、快、低黏度、立即移动和摊薄”。
8. 高风险动作数量是否超过预算。
9. `asset_paths` 和 `required_asset_tokens` 是否显式填写并匹配。

## 生成后语义验收

ffprobe 只能证明文件、视频流、音频流、时长和分辨率有效，不能证明产品正确。下载后必须另做视觉语义验收：

1. 全片按 1 fps 抽帧检查场景、人物和产品身份。
2. 每个高风险动作按 4–5 fps 抽帧，检查方向、三段几何、手指受力和液体位移。
3. 连排抽取逐帧核对：盒内方向 → 平移抽取 → 离盒同方向；若有旋转，必须完整可见。
4. 单支逐帧核对：蓝色标签尾端始终存在，颜色、形状和长宽比不变化。
5. 液体逐帧核对：短流快速断开，落地后立刻位移并摊薄。
6. 任一硬规则失败，将结果标为 `downloaded_media_valid_product_failed`；不得仅因 ffprobe 通过就称为成片成功，也不得自动重复提交。
