# 母版结构库

每条只选一个主结构。结构ID用于工作台记录和批次去重。

## L1 生活损失

**适合：** 抗老、眼周、颈部、状态型产品，中长口播。  
**骨架：** 具体事件 → 自我认知受损 → 尝试/顾虑 → 可信转机 → 产品证据 → 生活结果 → 行动。  
**必须继承：** 损失发生的因果、第一人称可信度、产品进入故事的自然转折。  
**创新槽位：** 拍照、上妆、会议、同龄对比、重要场合、家人一句话。  
**风险：** 过度羞辱年龄、婚恋和生育状态；虚构个人经历。

## S1 症状自检

**适合：** 15至30秒信息流，所有功效护肤。  
**骨架：** 点部位 → 点发生时刻 → 点可见后果 → 产品解释 → 镜头证据 → 收口。  
**必须继承：** 一个主问题贯穿，不扩成全脸问题清单。  
**创新槽位：** 眼下、鼻翼、下巴、脸颊；熬夜、妆前、洗脸后、空调房。  
**风险：** 症状堆砌、病理化诊断、绝对效果。

## C1 反常识纠错

**适合：** 有膜布、用法、频率或技术差异的产品。  
**骨架：** 旧做法可能不对 → 错在哪里 → 新方法/产品承担哪一步 → 可见证明 → 使用规则 → 行动。  
**必须继承：** “否定旧认知—解释原因—给替代方案”的逻辑。  
**创新槽位：** 使用顺序、观察角度、判断标准、错误示范。  
**风险：** 编造禁忌或产品强度；用“不能随便用”制造虚假门槛。

## T1 信任转交

**适合：** 高试错焦虑或高客单商品。  
**骨架：** 推荐关系 → 推荐者为什么有资格 → 为什么主动使用/推荐 → 第三方或可见证据 → 商品 → 机制。  
**必须继承：** 信任来源和推荐关系。  
**创新槽位：** 研发、质检、化妆师、长期用户、真实反馈。  
**风险：** 未授权明星、假采访、虚构检测、绝对担保。

## R1 仪式处方

**适合：** 面膜、眼膜、颈膜、涂抹面膜。  
**骨架：** 特定时刻 → 一个可模仿动作 → 使用顺序/频率 → 即时体感或妆效 → 产品理由。  
**必须继承：** 动作可执行，频率符合说明。  
**创新槽位：** 冰敷、睡前、妆前、出差、熬夜后、重要场合前。  
**风险：** 自编频率、把即时感受说成长期治疗。

## E1 证据翻译

**适合：** 有明确膜布、质地、结构或使用证据的产品。  
**骨架：** 用户问题 → 技术/设计 → 它解决哪一步 → 镜头如何证明 → 使用感 → 行动。  
**必须继承：** 技术、用户问题和画面三者一一对应。  
**创新槽位：** 服帖实验、质地展开、取用、拉伸、挤压、前后妆效。  
**风险：** 技术堆砌；镜头无法证明；跨SKU借成分。

## O1 机制冲突

**适合：** 当日有明确、可核验优惠。  
**骨架：** 原价/常态 → 今天差异 → 到手数量 → 单次成本或赠品 → 时效原因 → 行动。  
**必须继承：** 差异可计算，画面数量与口播一致。  
**创新槽位：** 价格阶梯、数量堆叠、单次成本、组合价值。  
**风险：** 假原价、假库存、假最后一天、长期使用限时话术。

## D1 问答成交

**适合：** 双人KOC、直播切片、生活化对话。  
**骨架：** 一人发现问题/提出异议 → 另一人回应 → 追问证据或价格 → 产品揭晓 → 行动。  
**必须继承：** 两个人的功能分工和问答顺序。  
**创新槽位：** 人物身份、地点、异议类型、反应强度。  
**风险：** 两人声音和视角互换；把解释写成旁白；假装路人采访。

## H1 主持揭晓

**适合：** 发布会、舞台、直播间或明确主持关系的母版。  
**骨架：** 主持人压场 → 观众/体验者反应 → 关键信息揭晓 → 商品/机制 → 行动。  
**必须继承：** 主持人是说话主体，观众只承担反应或证明功能。  
**创新槽位：** 场地、揭晓对象、反应方式、视觉装置。  
**风险：** 把主持人口播改成旁观者叙述；伪造大型活动或观众反馈。

## P1 产品观察

**适合：** 无强人设、产品镜充足的短视频。  
**骨架：** 先看一个细节 → 指出与常见产品不同 → 近景证据 → 使用动作 → 适用场景 → 行动。  
**必须继承：** 所说差异必须在画面里出现。  
**创新槽位：** 膜布边缘、鼻翼贴合、开盖质地、包装数量、使用后妆效。  
**风险：** 只拍高级感，不提供判断证据。

## A1 人群点名

**适合：** 15秒内快速筛选目标用户。  
**骨架：** 明确人群 → 一个高频时刻 → 一个主问题 → 产品与证据 → 行动。  
**必须继承：** 人群、时刻、问题三者相关。  
**创新槽位：** 熬夜上班族、空调房、宝妈、经常上妆、差旅人群。  
**风险：** 未经确认的敏感肌或特殊人群适用声明。

## N1 新闻/爆炸消息（限制使用）

**适合：** 只有在真实事件、真实发布和真实授权能够核验时。  
**骨架：** 事件 → 与用户的关系 → 可信来源 → 产品/机制。  
**必须继承：** 真实性和来源。  
**创新槽位：** 不建议把“新闻感”作为常规创新轴。  
**风险：** 假新闻、伪采访、伪官方发布。默认从候选中排除。

## 组合规则

- `S1 + E1`：最适合水润面膜和眼膜的短信息流
- `C1 + E1`：适合有真实用法或结构差异的产品
- `L1 + T1`：适合长口播，但产品转折必须自然
- `R1 + P1`：适合妆前、睡前、冰敷等场景
- `O1` 通常只放在尾段，不应吞掉产品证据
- `D1` 和 `H1` 是人物/场景结构，不应与母版视角互换
- `N1` 默认禁用，除非用户提供可核验来源
