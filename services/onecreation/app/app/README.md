# AI视频工作台 2.1.0

本地网页工具，当前包含四个独立入口：

1. `AI-产品镜生成`：支持水润面膜、黑晶面膜、晶润眼膜、燕窝胜肽面膜、凝颜套装、WIS 深海次抛及 WIS 肌活蛋白喷雾等产品镜生成。
2. `AI-KOC生成`：按 KOC LibTV Skill 完成原片深拆、资产锁定、提示词/分镜包、人工审核、LibTV生成和本地下载。
3. `AI-单视频批量裂变`：上传1条有效母版，LibTV分析核心成交逻辑，人工审核后生成1–10条可控裂变成片。
4. `AI-明星画面生成`：上传人物正面照生成三视图，或使用人物视频原片；可使用产品镜同一产品库生成人物手持与正确使用画面，也可选择“不出现产品”生成纯人物内容。

## AI-KOC执行边界

- AI原片深拆使用 LibTV `GVLM 3.1`，生成视频使用 `Seedance 2.0 VIP`。
- 人物候选图需先通过 LibTV/Codex 生成，由人工选定后上传本页；程序不会自动替人选图。
- 第一次提交只生成拆解、资产审计、分镜JSON和提示词包，不直接生成视频。
- 人工确认人物场景、产品露出与提示词后，第二次提交才会调用 LibTV。
- 参考音频应来自原片纯音频，长度大于1.8秒且不超过14.8秒；也可以明确选择本次不使用。
- 多分镜全片拼接需要本机可用的 FFmpeg；缺失时仍会保存每条分镜成片，并明确提示拼接卡点。

## AI-明星画面生成执行边界

- 人物正面照模式会先生成三视图，允许按调整要求单独重新生成，不清空后续产品与视频配置。
- 人物原片模式可保持人物身份、主要场景与动作连续性；填写新台词时根据接口能力自动选择可生成声音的模型。
- 产品手持与使用动作实时使用产品镜的产品资料、产品插件和正确使用规则，固定禁止新增口播字幕或不明屏幕文字。
- 选择 `不出现产品` 时不会上传产品图，任务改为纯人物主持口播与场景表演，并禁止生成商品、包装、品牌、价格、功效和购买引导。
- 自动读取本机 FanDo/OpenClaw 登录凭证并在内存中换取 JenVideo gen_token；凭证不写入任务记录。
- 生成前必须确认人物肖像及上传素材已取得使用授权。

## 单视频批量裂变执行边界

- 文案强度已经拆成三条明确规则：稳健版沿用母版原口播，只替换目标商品事实和不合规原词；均衡版以母版原文为底稿，只小改一处钩子、转折或收口；大胆版可以完整创新文案，但必须保留说话人身份、人物与场景关系、核心吸引逻辑和成交顺序。
- 母版分析新增逐字 `copyBeats`、说话人视角、人物与场景关系、情绪机制和声音表演拆解。每个生成镜头都单独绑定说话人、口播、情绪、语速、音量、重音和停顿，台下反应镜头不会被错误分配主持人口播。
- 任务卡显示与“母版商品替换底稿”的相似度，并允许人工编辑“人物情绪与声音导演说明”。稳健改动过大、均衡偏离母版、人物视角错位、商品口径错误或出现内部占位语时，会在提交LibTV前阻止生成。
- 为避免旧缓存缺少逐字口播和人物视角，新版会对旧母版分析缓存自动失效并重新分析一次；之后同一母版继续按新缓存复用。
- 自动质检只连接裂变成片，母版使用准备阶段缓存的结构分析对照，避免 GVLM 两路视频输入校验失败。
- 自动质检技术失败会轻量重试一次；仍不可用时保留成片并进入人工复核，不重新生成视频。
- 产品镜、KOC、单视频裂变均固定禁止自动字幕、口播字幕和任何跟随人声的字幕条；口播只以声音呈现。
- 画面并非禁止一切文字：产品包装、正确的品牌/舞台/门店标识、已审核价格规格和必要行动提示可以出现，但必须逐字正确；自动质检会单独拦截错字、乱码、错误商品信息和未审核促销文字。
- 自动质检不通过或技术不可用的单条成片均可点击“重新生成本条”；技术不可用时仍保留“仅重新质检”，两种处理方式互不覆盖。
- 单视频裂变页新增持久化任务列表，可查看最近50个历史任务、重新打开成片和输出目录；刷新、重启或更新程序后仍从 `app\jobs` 恢复。
- 单条重新生成会保留旧版成片并生成新的 `_v2`、`_v3` 文件，任务卡可回看以前版本。
- 自动质检完成画面、结构、产品、无口播字幕与画面文字准确性检查；口播逐字准确性和价格口径仍需人工抽听确认。

- 母版先使用 LibTV `GVLM 3.1`识别钩子、痛点、解决方案、卖点顺序、人物关系、行动引导和镜头功能。
- 三款主推商品已内置审核后的价格规格：水润面膜169元/4盒40片；晶润紧致眼膜59元/1罐60片或99元/2罐、每罐60片；黑晶面膜59元/1盒10片或99元/2盒、每盒10片。每批必须明确选择一个价格口径或选择不口播价格。
- 每条任务卡会先生成可编辑的最终口播、人物情绪与声音导演说明和母版逐镜对位表；口播必须明确使用目标产品，选择价格后必须逐字包含该价格与数量。
- 稳健、均衡和大胆三档都连接母版视频：稳健保留原文与表演，均衡只做小幅文案创新，大胆可重构文案与视觉但仍锁定说话人视角、人物场景关系、钩子、因果、镜头功能、产品节点和行动引导。
- 稳健、均衡、大胆数量均可独立设置为0–10条，三档合计1–10条；不再按固定比例自动分配。
- 换产品默认直接调用产品镜模块的产品图库，也可在任务页追加产品、人物和背景参考图。
- 人工确认核心逻辑、资产来源和每条任务卡后，才调用 `Seedance 2.0 VIP`生成分段。
- 长视频按不超过15秒的分段生成，优先使用 LibTV `video-clip`合成完整视频；失败时尝试本机FFmpeg备用合成。
- 生成后会自动比较母版与成片文件指纹，并使用LibTV同时检查母版逻辑一致度、镜头顺序、人物功能关系、因果链、目标产品、口播价格、音频清晰度和多镜头完整性。
- 完整成片合成后立即显示播放器，后台质检不阻塞预览；质检提示问题时保留成片供人工判断，不自动整条重做，确认确有问题后可单条重试。
- LibTV CLI返回“节点创建JSON + 最终结果JSON”时，程序只读取最终运行结果的`data.url[0]`，并拒绝把母版上传地址当成成片；历史任务可从已保存日志找回真实生成结果，不重复消耗模型点数。
- 产品、人物和背景图片进入裂变任务前统一执行LibTV安全尺寸保护：长边不超过2048px、文件不超过4MB；因图片像素上限失败的单条重试会自动刷新图片和画布引用。
- 裂变生成采用全量并发：选择几条就同时向LibTV提交几条，同一成片的多个分段也并发生成；任务卡按条增量刷新，一条完整成片完成后即可立即播放。
- 相同母版的逐镜分析会按文件指纹缓存复用，避免重复分析；每条裂变任务使用独立节点名、输出文件和重试状态。
- 产品镜结果也按条增量刷新：一条下载完成就立即显示播放器，后续轮询不会重建已出现的播放器或中断正在播放的视频。
- 目标成片时长约为母版加1秒，并按LibTV单段4–15秒约束重新拆分。
