# 人物营销视频生成器

独立人物营销视频工具，运行时实时读取 AI 视频工作台“产品镜生成”的同一产品库，包括内置产品、产品插件、产品图、视觉识别、质地说明、使用动作与合规约束。

当前 JenVideo 生产接口：`https://jenvideo-jump.fandow.com`

## 功能

- 上传人物正面照生成正面、左 45°、右 45°三视图。
- 输入调整要求后可单独重新生成三视图，不清空其他设置。
- 也可直接上传人物视频原片作为身份与动作参考。
- 自动生成 15 秒人物手持产品视频。
- 自动生成 15 秒产品正确使用视频，次抛等特殊形态会沿用产品镜专属动作限制。
- 产品可选择“不出现产品”；此时不上传产品图，改为生成纯人物主持口播和场景表演视频。
- 可填写人物口播台词；三视图模式由 Kling 优先生成带声音口播，视频原片模式会根据接口限制自动使用 Seedance 生成新声音。
- 每类视频可一次生成 1–4 个候选版本，即一次任务共生成 2、4、6 或 8 条视频。
- 多候选任务按每批 2 条提交，降低接口瞬时并发导致的失败率。
- 成片 OSS 地址返回 403 时，自动切换到 JenVideo 带鉴权代理下载并重试。
- 支持 Seedance 2.0、Kling Omni 和自动降级；自动模式优先 Kling Omni，可灵失败时切换 Seedance 2.0。
- 生成前自动校验 Base URL 与 gen_token，避免素材提交后才发现配置错误。
- 产品图和人物素材逐个显示上传进度；临时网关故障自动重试 2 次。
- 准确区分“准备失败”和“视频生成失败”，未提交的视频会显示“未开始”。
- `ring-balancer`、token 失效、地址错误和额度限制均提供中文处理建议。
- 自动将旧接口 `cloud.fandow.com/gpt/JenVideo-jump` 迁移到新生产域名。
- 自动读取 `%APPDATA%\FanDo\auth\session.json` 中的 `accessToken`，调用 `/v1/agent-token` 换取 gen_token。
- 自动获取的 UAC token 和 gen_token 只在本机内存及鉴权请求中使用，不写入任务记录；页面无需手动填写。
