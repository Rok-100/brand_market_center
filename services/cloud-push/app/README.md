## 行为

- 大约每五秒观察一次已提交的数据库状态；数据库读取失败会等待下一轮。
- 每个视频、每个目标推送任务独立通知。入队、成功、失败、部分完成、待平台确认、取消均有对应卡片。
- 轮询之间瞬时经过的状态可能不单独通知；以观察到的持久化状态为准。
- 卡片包含视频名、目标账号/计划、操作人、状态、任务编号、北京时间及工作台按钮。
- 首次启动建立历史基线，不发送历史记录；既有任务后续发生状态变化仍可通知。
- 普通进度或指标更新时间变化不重复通知。通知重试不重新推送视频。
- 接收人、卡片内容和飞书 UUID 在首次发送前持久化，重试保持一致。
- 最多自动发送五次；不确定结果超过幂等时间窗口后停止自动重发，状态为 `attention`。
- 未匹配到飞书账号的任务保留在通知队列，错误码为 `recipient_mapping_missing`，不会猜测接收人。
- 更新接收人配置后只需重启独立通知容器；历史基线和通知回执继续保留。
